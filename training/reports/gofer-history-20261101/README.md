# 과거 화선 이력 보강과 접근 분류 비교 — 2026-11-01

미국 GOFER 자료에서 위치 주변 2km에 최초 접근하는 1/3/6시간 연구 점수의 **사건별 균등 평균 AP는 개선됐지만, 전체 사건을 합친 AP는 기존 AFT보다 하락했다.** 국내 개인 영향 확률이나 대응 지침의 검증을 통과한 것은 아니다. AP는 정확히 맞춘 비율이 아니며 아래 0.331을 정확도33.1%로 표시하지 않는다.

## 변경과 고정 조건

- 기존28사건·153,325행·정답 구간·연도 분할·연구반경2km를 그대로 보존했다. train은2019/2020 17사건106,739행,2021 개발검증은11사건46,586행이다.
- 기존7개 입력에 과거1/3/6/12시간의 거리·실제 경과시간·접근속도·면적 증가율·성장 방향28개를 추가했다. 부족한 이력은NaN와known=0으로 두며 미래 경계를 참조하지 않는다. [정확한35개 입력 정의](dataset/config.json), [행·해시 검증](dataset/report.json).
- 하나의 이진 분류기에 horizon을 추가하고 거리감소/기간증가 단조제약을 줬다. 이전 AFT와 목적함수도 다르므로 개선을 신규 피처만의 효과로 주장하지 않는다.
- train 사건 시작부터78시간의 겹침을 묶은7개기간cluster에서 outer4/inner3 중첩검증을 했다. 후보6개·최대101회적합·CPU2·seed47를 사전에 고정했다. 시간순 미래 예측 검증이나7개의 통계적 독립성을 입증한 것은 아니다.
- 선택, 양의 기울기 공통sigmoid 보정, 후보 알림 기준은 각outer기간을 제외한 innerOOF에서만 학습했다. 기준의recall80은1/n(event,h)의 표본가중 재현율이며 사건별 평균80% 또는 새 사건80% 보장이 아니다. 최종전체train 선택 영수증 이후에2021을 읽었다.2021은 이미 본 개발검증이므로 새 비공개 시험으로 부르지 않는다.
- GOFER는 사후 위성 재구성이다. 과거 시각의 피처만 사용해도 원자료의 최종 경계 후처리·거친 관측 해상도·실제 당시 가용성 미확인 한계가 제거되지 않는다.

## 실제 결과

101회 적합은151.375초에 끝났고, 최종선택은 `history_d2`(depth2,150rounds)다. 저장 모델의 재로딩 예측 차이는0이었다. [계획](model/plan.json), [선택·보정 동결 영수증](model/fit-receipt.json), [전체 평가](model/report.json).

| 평가 | 단순 현재 거리 AP | 새 분류 모델 AP | raw Brier | 보정 후 Brier |
| --- | ---: | ---: | ---: | ---: |
| train의 outer기간 제외 평가 | 0.179247 | 0.256923 | 0.006804 | 0.006820 |
| 2021 개발검증 | 0.262214 | 0.331149 | 0.003088 | 0.003117 |

AP는 양성과 음성이 모두 있는 사건×기간을 균등 평균한다. train48/51,2021 26/33개가 AP 계산 대상이며, 단일클래스 사건도 Brier·오탐 집계에는 포함한다. train6h의 정답 미상644행을 음성으로 채우지 않았다. 거리 점수는음수km여서 Brier를 정의하지 않는다.

같은2021행의 기존 AFT AP는0.259488로 새 모델은약27.6% 상대 향상이다. 이는 서로 다른 목적으로 학습한 두 방법의 개발검증 비교다. 기존전체train으로 적합한 AFT를 새outer평가와 비교하지 않았다. 같은학습fold의고정후보 비교에서도 기존7피처 depth2 AP0.253906,35피처 depth2 AP0.274600이었다. 이 수치는 **후보 선택에 쓰인 OOF**이며 독립 성능 추정인outer평가와 구분한다. [모든후보](model/final-selection.json).

공통sigmoid 보정은 두 평가에서 Brier가 오히려 소폭 악화됐다. 보정된확률의 신뢰성이 입증됐다고 주장하지 않는다. 미국 연구 격자·사건별 가중분포를 사용했으며 사용자집단의 피해확률을 나타내지 않는다.

동일2021 자료를 사건 구분 없이 합친 AP는1h 기존AFT0.22240→새모델0.21165,3h0.27044→0.23230,6h0.29097→0.26961로 모두 떨어졌다. 사건별 순위와 사건간 점수 비교의 성능이 다르므로 전반적으로 우월한 모델이라고 결론내리지 않는다. 거리 대비 nested7기간중5개개선/2개악화,사건×시간48개중36승12패이며2021도26개중16승10패다. 기존 모델을 폐기하거나 새모델만 운영용으로 채택할 근거가 아니다.

| 2021 개발검증의 고정 후보 기준 | 1h | 3h | 6h |
| --- | ---: | ---: | ---: |
| 양성 관측 수 | 55 | 170 | 294 |
| 새 모델 재현율 | 92.73% | 85.29% | 84.69% |
| 새 모델 정밀도 | 5.69% | 8.22% | 8.91% |
| 전체 후보 중 표시 비율 | 1.93% | 3.79% | 6.00% |
| 거리 기준 재현율 | 100.00% | 88.82% | 81.29% |
| 거리 기준 정밀도 | 1.49% | 4.10% | 6.49% |
| 거리 기준 표시 비율 | 7.90% | 7.90% | 7.90% |

위 표는 모든 행을 합친 진단이다. 사건별 성능 차이를 가리지 않도록 원본 전체와 [독립 재계산](independent-review.json)을 함께 보존한다. 2021양성이있는26개사건×시간중8개는재현율80%미만이며KNP는3h29.41%,6h38.10%다. Nested도48개중17개가80%미만이다. 새모델의합산6h재현율은 높아졌지만 표시후보의91%가량은 해당 위성 정답상 음성이다. 이 기준을 실제 사용자 경보·대피 단계로 사용할 근거는 없다.
