# 국내 과거 비화재 관측 집단의 모델 비교

2026-11-01 KST. **57회 비교 학습을 완료했으나, 이번 이력·바람 보강을 성능 개선으로 채택하지 않았다.** 최종 교차검증은 기존 34개 입력을 선택했다. 현재 화재까지의 거리 기준보다 전체 평가에서 일관되게 우수하지 않으며 개인 대응 판단용 확률로 사용할 수 없다.

이 실험은 국내 2020~2022년 학습 창 14개만 사용한다. 2023 검증·보정 및 2025 시험 자료를 열지 않았다. 이미 여러 연구에 사용한 학습 사건의 탐색적 기간 분리 검증이며 새로운 독립 최종 평가가 아니다. 모든 결과의 `probability_calibrated`와 `operational_use`는 `false`다.

## 자료와 비교 조건

[자료 생성·스키마·재현 명령](README-dataset.md), [원본 보존 감사](report.json), [집단별 관측 범위](cohort-counts.json)를 별도로 보존했다. 현재 입력으로 정한 전체 후보는 466,710행이고, 기존 315,490행의 정답·기본34개 입력은 모두 동일하다. 미래 관측 불명확 151,220행을 추가 보존했다. 기존 코드도 이를 음성으로 만들지는 않았다.

주 분석은 과거60분 예정7회 모두 명확 비화재이고 확보된120분 이력에 화재 관측이 없는 후보다. 각1·3·6시간에134,710행씩, 합계404,130행이며 알려진 정답287,824행만 학습한다. 미래 관측이 불명확한116,306행도 평가 시 모델 점수와 상위10% 검토 예산에 포함한다. 6시간의 불명확 비중은46.13%다. 물리적 최초 발화·화선 도달 또는 개인 피해의 정답은 아니다.

| 후보 | 입력 수 | 변화 |
| --- | ---: | --- |
| A | 34 | 기존 환경·거리·관측 이력 입력 |
| B | 44 | 기존 고정 분모의 접근 속도2열을 빼고 실제 스캔 간격·속도 및 과거60/120분 관측 범위12열 추가 |
| C | 50 | B에 최근 화재 방향의 바람·거리와 공기 건조도 VPD6열 추가 |

열 개수는 독립적인 신규 정보의 개수가 아니다. [실제 입력 변동 감사](feature-variation.json)에서 추가12열 중7열은 상수였고, 실제20/50분 속도는 기존 속도의1.5/1.2배였다. 트리 분할에 새로운 순서 정보를 주는 변화가 아니며, 후보별 열 구성·열 표본추출 효과와120분 관측 범위 변화를 함께 비교한 것이다. VPD는 연료 수분이 아니다.

11개 기간 그룹의 outer4/inner3 교차검증을 사용했다. 외부 평가 기간을 제외한 내부 fold의 알려진 정답에 대한 사건×기간 평균 AP로 후보를 선택한다. 양성 가중치는 각 학습 fold 안에서만 계산한다. CPU2개·100개 트리·seed47을 고정했고, 별도로 A를 각 outer 학습 기간에 다시 적합해 대조군을 만들었다. 같은 사건의 전체학습 모델을 그 사건의 독립 평가로 사용하지 않았다.

## 실제 결과

AP는 **분류 정확도나 확률 보정 성능이 아니다.** 아래 AP는 양성·음성이 모두 있는25개 사건×예측기간의 알려진 정답만 평균한 값이다. 상위10%는 미래 정답을 보기 전에 시점별 모든 후보에서 선택하며, 반올림 때문에 실제 선택 비율은10.10%다.

| 평가 방법 | 사건×기간 평균 AP | 상위10% 관측 양성 재현율 | 선택된 알려진 정답의 정밀도 | 선택 후보의 정답 불명확 비중 |
| --- | ---: | ---: | ---: | ---: |
| 새 후보 중 내부 검증으로 선택하는 절차 | 0.22588 | 35.45% (379/1,069) | 1.416% | 34.41% |
| 고정 A34를 각 outer에서 다시 학습 | 0.23626 | 35.36% (378/1,069) | 1.417% | 34.63% |
| 최근60분 화재까지의 거리 | 0.20585 | 37.14% (397/1,069) | 1.443% | 32.59% |
| 현재 화재까지의 거리 | 0.23178 | 38.07% (407/1,069) | 1.479% | 32.57% |

새 선택 절차는 최근 거리보다 AP가 높지만 현재 거리보다 낮고, 상위10%에서 현재 거리보다 관측 양성28행을 더 놓쳤다. 알려진 정답만의 정밀도가 약1.4%이므로 개인 경보에 바로 쓰기 어렵다. 이 행들은 여러 판단 시점·예측기간에 반복되는 후보이며 고유 화재·사용자·알림 수가 아니다.

[독립 재계산](independent-review.md)은8,391개 수치 항목을 대조했고 최대 절대차1.11×10⁻¹⁶으로 일치했다. 거리보다 추가로 놓친79행 중54행이 울진에, 추가로 포착한51행 중47행이 영덕·밀양에 집중됐다. 양성이 있는250개 시점×기간 중 모든 양성을 놓친 경우는 새 절차75개, 현재 거리104개여서 일부 작은 집단의 누락은 줄었지만 전체 양성 포착 수는 나빠졌다. 동점 선택을 고려해도 새 절차의 가능한 포착 수378~379는 현재 거리407에 미치지 않는다. 고정A 대비1행 차이는 동점 가능 범위가 겹쳐 우월성 근거로 삼지 않는다.

선택된40,806행 중14,042행은 정답을 알 수 없다. 이를 전부 음성/양성으로 가정했을 때 **인코딩된 위성 관측 정답에 한한** 전체 선택 정밀도 범위는0.929~35.340%로 매우 넓다. 실제 화재·피해의 통계적 신뢰구간이나 개인 위험 확률 범위가 아니다. 알려진 정답만으로 선택·학습하는 관측 편향도 여전히 남는다.

120분 예정13회 모두 명확했던334,515행의 민감도 평가에서는 같은 외부 평가 모델을 그대로 사용했다. 새 절차의 AP0.14607, 재현율30.13%이고 현재 거리의 AP0.15442, 재현율30.90%다. 민감도 집단 안에서 상위10%를 다시 정했으므로 주 분석의 선택 후보와 단순 교집합이 아니다. 서로 다른 집단의 수치를 모델 성능의 전후 변화로 해석하지 않는다.

최종 전체 학습의4-fold 선택 점수는 A0.2362646, B0.2321962, C0.2261799로 **A34**가 선택됐다. outer별 선택은 C/B/A/A다. 최종 선택 점수는 후보 선택에 사용한 수치이며 별도 독립 성능이 아니다. 기존 v4 보고서와는 집단·정답 가용성·검토 예산이 달라 이번 숫자를 그대로 비교해 정확도가 올랐거나 떨어졌다고 판단하지 않는다.

## 실행·검증·저장

실제 학습·평가 시간은111.196초, 총57회다. 저장 모델100개 트리, CPU 재로딩 최대차0,404,130행의1→3→6시간 단조성 위반0을 확인했다. 종료 직전 입력·코드·계획41개 파일의 SHA가 동결 계획과 일치했다. 전체 학습 테스트506개가 통과했고, 기존 Affine 연산의 폐기 예정 경고54개만 남았다. [테스트 결과](tests.xml), [동결 학습 계획](model/plan.json), [전체 모델 결과](model/report.json)를 보존한다.

| 산출물 | 경로 |
| --- | --- |
| 새 자료 | `data/processed/korea-first-observation-train-20261101-v2/` |

모델·예측은 로컬의 같은 상대경로에도 회수했다. 자료 Parquet는 서버에 두고 작은 감사 보고서만 저장소에 보존한다. 완료된 출력은 덮어쓰지 않는다. 새 비교 실행은 다음처럼 별도 출력 이름으로 계획을 먼저 동결한다.

```bash
  --dataset data/processed/korea-first-observation-train-20261101-v2 \
  --output "$COHORT_MODEL_OUTPUT" --plan-only
training/.venv/bin/python -m bonghwa_training.korea_first_observation_train \
  --dataset data/processed/korea-first-observation-train-20261101-v2 \
  --output "$COHORT_MODEL_OUTPUT" --run-frozen
```

## 확보한 추가 자료와 남은 조건

[국내 화선·산림 자료 조사](../korea-source-alignment-20261101/public-label-sources.md)에서 실제 WorldCover2021 원본을 확보했다. 하지만2022-10-28에 공개됐으므로2022년봄 산불 당시 입력으로 쓰지 않았다. 국내 시간별 실측 화선 GIS는 아직 확보하지 못했다. 논문의 공개 라이선스를 미공개 GIS에 확대 적용하지 않는다.

KMA의 추가 기상 경로6개는403으로 거부됐지만, NOAA GFS의2022-03-03 18UTC cycle/+7시간 예보에서 실제 U/V10m·기온/습도2m를 확보하고 원 GRIB의 시각·높이·진북 성분을 확인했다. 이 자료는 별도 연결 검증 단계이며 **이번57회 학습에는 넣지 않았다.** 실제 최초 공개·수신 지연은 확인되지 않았고,0.25도 기상이 지역 화선 주변의 바람을 정밀하게 대변한다는 증거도 없다.

이번 결과는 현재 자료에서 가능한 최고 성능을 증명하지 않는다. 검증된 개선을 위해서는 당시 가용한 예보·정적 자료의 정합, 더 다양한 국내 사건, 관측 불가와 구분된 시간별 실제 화선 정답이 필요하다. 현재 모델의 점수를 사용자 개인 대응 매뉴얼의 영향 확률이나 대응 단계로 연결하지 않는다.
