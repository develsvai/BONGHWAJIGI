# 국내 2019~2023 산불 시간별 경계 정답 자료 조사

- 조사일: 2026-11-01 KST
- 대상: 국내 사용자 위치의 향후 1~6시간 산불 접근 검증에 필요한 실제 화선·영역의 시계열 정답
- 결과: **국내 사건, 시간별 실제 경계, 직접 다운로드, 명시 재사용 라이선스를 모두 충족하는 자료는 이번 조사에서 확인하지 못했다.** 자료가 존재하지 않는다는 뜻은 아니다. 공식 PDF 3개를 실제 내려받았으며, 국립산림과학원(NIFOS)의 2023년 다중 시점 경계 원자료는 요청 방식으로 제공된다고 확인했다.
- 실행 경계: 인증 API 호출·모델 학습·평가에는 사용하지 않았다. 2025년 사건 원자료·정답 파일을 열거나 내려받지 않았다. 검색엔진이 혼합 연도 논문의 2025년 포함 표 일부를 자동 반환한 경우 해당 논문·부록·원자료를 추가 열람하거나 데이터셋에 편입하지 않았다.
- 아래 시각은 원문 표기를 보존했다. KST/UTC가 명시되지 않은 자료는 아직 UTC로 확정 변환하지 않았다.

## 3. 정답 구축 전에 해결할 사항

1. **관측 시각, 상황도 기준 시각, 작성·전파 시각, 사후 공개 시각을 구분한다.** 2024년에 발간된 백서는 2023년 사건의 사후 정답 출처가 될 수 있지만, 그 지도가 2023년 해당 예측 시각에 시스템 입력으로 이용 가능했다는 증거는 아니다.
2. NIFOS 논문 사례 4는 Table 1의 발화 시각이 `2023-04-03 14:15`, 첫 경계 취득일은 `2023-04-04`로 표시되어 서로 맞지 않는다. 오타로 추정하여 자동 수정하지 말고 원자료와 저자 확인으로 해결한다. 표의 면적 0인 발화점을 관측 경계로 세지 않는다.
3. `4/2 24:00`은 정규화 시 `4/3 00:00`으로 옮길 수 있지만, 원문 시각과 적용 시간대를 별도로 보존한다. 시간대 확인 전 UTC 정답으로 확정하지 않는다.
4. 진행 중 화선·진화 완료 화선·피해 추정 영역·실제 연소 영역은 서로 다른 라벨이다. 지도 선이 없는 곳이나 위성 비탐지·구름 영역을 비연소 음성으로 채우지 않는다.
5. GIS 원본이 없으면 기준점·CRS·원본 지도 해상도·지오리퍼런싱 잔차·수작업 경계 판독 오차를 기록해야 한다. 지도 이미지의 픽셀 크기를 실제 100m 정답 정확도로 간주하지 않는다.
6. 사후 최종 피해 경계로 초기 후보 지역·음성 표본·피처를 제한하지 않는다. 최종 경계는 사후 평가용으로만 분리할 수 있다. 늦게 확인한 미래 경계로 초기 화선을 보정한 뒤 실시간 예측 성능이라고 보고하지 않는다.
7. GK2A·VIIRS 탐지점은 탐지 해상도·위치 오차·누락·관측 간격을 가진 화재 관측이다. 연속적인 실제 화선이나 모든 미탐지 지점의 안전을 보장하는 정답이 아니다.

## 4. 다음 확보 요청의 구체 항목

최우선은 NIFOS 논문의 **2023년 사건 4개 원본 다중 시점 경계**다. 기관·저자에게 아직 연락하지 않았다. 실제 제공을 요청할 때에는 아래 항목이 필요하다.

- 경계의 원본 SHP/GeoPackage/GeoJSON/GeoTIFF, CRS 및 수평 위치 정확도
- 사건 ID, 발화 위치·시각, 각 경계의 관측 시각과 시간대
- 관측 시각과 별개인 상황도 작성·전파·수정 시각 및 당시 이용 가능성
- 관측 방법(헬기·드론·현장·수작업 상황도)과 누락 영역·불확실성
- 진행 화선·진화 완료 선·비연소 내부 영역의 의미와 진화 개입 기록
- Table 1 사례 4의 날짜 불일치 정정, 발화점과 실제 경계의 구별
- 학습·검증·파생 GIS 생성·모델 공개·시연·상업 서비스·재배포 각각의 이용조건과 출처 표기 방식

이 조건을 해결하기 전에는 내려받은 PDF나 논문 그림을 확정 학습 정답으로 전환하지 않는다. 국내 1~6시간 실제 접근 확률의 정확도·보정을 검증했다는 주장은 할 수 없다.
