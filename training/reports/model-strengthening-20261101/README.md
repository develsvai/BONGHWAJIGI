## 개선 효과와 남은 실패

GOFER는 원래28사건·153,325행·정답을 유지했다. 과거1/3/6/12시간의 이동과 면적·방향을 추가하고, 비슷한 기간의 사건을 묶어 선택·보정·평가를 분리했다. 최종 선택 모델은 `history_d2`다. 훈련기간을 제외한 평가에서 AP0.2569로 거리기준0.1792를 넘었다. 그러나7개기간 중2개는 악화했고2021 KNP 사건의6h 재현율은38.1%에 그쳤다. 전체2021의6h 후보 정밀도도8.9%여서 다수 오탐이 남는다. 공통sigmoid 보정은 Brier를 소폭 악화시켰다. [상세·모든 후보·재현 명령](../gofer-history-20261101/README.md), [독립 검산](../gofer-history-20261101/independent-review.md).

국내 실험은14개 학습 창·11기간그룹·315,490개 후보×시점×기간 행만 읽었다. 원래34개 입력, 최근 화재 기준 바람을 넣은38개, 공기 건조도VPD까지 넣은40개 후보를 비교했다. 최종 내부 선택은40개 후보지만, 외부기간 평가에서 선택된 것은 기존후보1회와 바람후보3회다. 최종40개 모델이 독립 평가에서 더 좋아졌다고 주장하지 않는다. 같은31,932개 후보를 검토했을 때 양성 포착960개 대 거리기준881개였으나, 정밀도는3.01%에 불과했다. 이 수치는 기간별 중복을 포함하는 관측 수이며 사용자 수가 아니다. [국내 전체 결과](../korea-recent-wind-20261101/report.json), [독립 검산](../korea-recent-wind-20261101/independent-review.md).

국내 추가 포착79개 중63개는 영덕2022에 집중됐다. 기간별 AP는5개 개선·5개 악화·1개 정의불가였고, 양성이 있는448개 시점×기간 중41개는 상위10%에서 양성을 하나도 잡지 못했다. 평균 개선을 모든 사건에 고르게 적용되는 효과로 해석하지 않는다.

실제 수관 보강은 바람 차폐와 수관화의 영향을 분리했다. 수관화를 켜면 같은 수관의 지표화만 사용한 경우보다 확산이 늘었지만, 기존 수관없음 결과를 넘지 못했다. 원자료의 수관 변수 불일치7,331셀은 임의 수정하지 않고 QC로 남겼다. 실제6h 적분 완료를 확인했으며 결과를 보고 수분이나 확산 배율을 다시 맞추지 않았다. ## 다음 성능 개선의 핵심

현재 자료에서는 추가 학습 횟수보다 **정답과 실제 입력의 정합성**이 큰 병목이다. 국내 자료에는 이미 화재가 관측된 셀의 재탐지와 멀리 떨어진 신규 탐지가 섞여 있다. 풍향·기상 관측의 공간거리와 시간 지연도 크고 강수는 전량 결측이다. 실제 접근 확률을 만들려면 같은 산불의 시간별 화선·관측불가 구간을 확보하고, 당시 가용한 바람·지형·연료를 연결한 국내 목표 데이터가 필요하다. 현재 확보한 공식 백서·국내 연구의 GIS 원자료 경로와 미확정 이용조건은 [기존 조사](../gofer-hindcast-20261101/domestic-label-sources.md)에 남겼다.

추가 후보를 같은2021/2023 정답에 반복해서 맞추는 방식은 새로운 검증을 만들지 못한다. 새 국내 정답·가용성 검증을 확보한 뒤 사건·기간을 잠근 평가로 확인해야 한다. 공식 긴급경보와 사용자 프로필·대응 지침 경로가 이 연구 점수의 신뢰성을 대신 보증하는 것은 아니다.
