원래 추적하던 **178개 파일**(문서·자료 177개와 수집 폴더의 `.gitignore`)은 [문서 이동표](문서_이동표.csv)에서 이전 경로·현재 경로·통합 절·이전 SHA-256으로 전수 대조할 수 있습니다. 이전 문서 안내의 오래된 링크 목록은 이 안내로 교체했습니다.

기존 Loom 대기 작업 3개의 필수 문서 ID를 보존하기 위해 `V2` 아래에는 **이동 안내 4개만** 남겼습니다. 내용은 모두 역할별 한글 경로로 이동했으며 이 안내 파일에는 본문을 복제하지 않습니다. 작업 ID·의존관계·대기 상태를 바꾸지 않았습니다. 내용이 다른 발표 시안·초기 설계는 중복 파일로 지우지 않았습니다.

이미지·PPTX·DOCX·XLSX·CSV 및 실행 증거 JSON의 본문과 해시 값은 보존했습니다. 공유 대화는 메시지 원문을 보존하고 탐색 링크와 파일 위치 목록만 고쳤습니다. 발표 파일 보존 목록도 새 경로로 갱신했습니다. Word·Excel의 과거 인계본에 남은 경로는 당시 기준이며, 현재 실행 명령은 Markdown 안내를 사용합니다.

과거 Loom 완료 기록·학습 출처·보고서 JSON·아키텍처 출처 JSON에 들어 있는 경로는 **기록 당시 경로**로 보존했습니다. 해당 경로가 지금 없으면 이동표에서 찾습니다. 해시와 옛 실행 시점의 의미를 바꾸지 않기 위한 처리입니다. 수집 원본 목록의 `data/raw/` 역시 원래 인계 패키지 경로이며, 현재 수집 도구는 이를 `04_데이터수집/자료/raw/`에서 찾습니다.

이전부터 빠져 있던 최종 발표 PPTX·ZIP·장문 라이선스 문서는 복원하지 않았습니다. 남아 있는 미리보기·제작 원본·조사 기록으로 안내합니다.
