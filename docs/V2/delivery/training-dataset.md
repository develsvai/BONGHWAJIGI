# 학습 자료와 실제·합성·미관측 구분

2026-11-01 KST. 초기 Loom 계획의 산출물 경로를 현행 산불 MVP의 구현·검증 기록에 연결하는 완료 근거입니다. 아래 링크의 상세 문서·코드·보고서를 정본으로 사용합니다. 이번 상태 정리에서 서비스 배포나 모델 실행을 새로 수행하지 않았습니다.

[초기 실제 자료 구축](xgboost-training-data.md), [학습 README](../../../training/README.md), [자료·분할·품질 및 실험 기록](korea-wildfire-improvement.md)에 재현 경로를 보존합니다.

- 실제 NDWS·GOES·GK2A 관측, GOFER 경계와 기상/지형 입력은 각각 출처·단위·시각·판본·권리·해시·가공 내역으로 구분합니다.
- 실제 관측의 train/validation/test와 연구별 사건·기간 분할을 보존하고, 미래 미관측·구름·누락을 비도달0으로 채우지 않습니다.
- 합성 CUDA 연결 시험·물리 확산 시나리오는 별도 simulation 산출물입니다. 실제 자료와 섞어 성능을 주장하지 않습니다.
- 국내 첫 관측 재구축 및 GFS2022 비교는 모집단·시점이 다르며 이전 표와 단순 전후 비교하지 않습니다.
- 국내2025 holdout의 기존 미열람 조건과 source_asof 미검증 한계를 유지합니다.

현재 확률의 운영 타당성은 미입증입니다. 국내 실제 접근 정답·화선·당시 가용 입력의 보강은 대기 작업이며, 자료 구축 완료가 실제 개인 예측 연결 완료를 뜻하지 않습니다.
