# A·B 촬영 시나리오와 지역 안내 파이프라인

2026-11-01 KST. 사용자 제공 `봉화지기 2분 시연 영상 계획`의 같은 산불·서로 다른 사용자 흐름을 구현한다. 이 문서의 검증 결과는 실제 실행 후 갱신한다.

## 데이터와 판단의 구분

[수집 자료](../../../data/filming/yeongdeok-20250325.json)는 2025년 3월 의성 산불의 영덕 확산, 정부의 전국 산불경보 심각 발령 기록, 기상청의 사후 기후 분석, 현재 공식 행동요령·준비물 자료를 포함한다. [출처·이용 조건](filming-sources.md)에 URL, 원시 시간의 정밀도, 이용 범위를 기록한다.

개별 주민대피명령의 CBS 전문은 확보하지 않았다. 정부 공식 보도에 포함된 전국 심각 발령 문장만 정보 경보로 입력하며, 이를 개인 대피명령으로 바꾸지 않는다. 2025년 당시 공개 정보를 그대로 재현하는 백테스트가 아니라 공개 자료를 이용한 현재 실행 시점의 파이프라인 재생이다.

| 입력 | 출처·해석 |
| --- | --- |
| 전국 심각 발령 | 정부 공식 보도에서 확인한 과거 기록, `instruction_kind=information` |
| 건조·강풍 | 정부 대응 기록과 기상청 대구·경북 사후 분석; 개별 사용자 위치의 실시간 관측 아님 |
| 안개 | 미확인/null. 연기나 연무를 안개로 바꾸지 않음 |
| 영덕 산림·산지 | 영덕군 공식 지리 소개. A/B 좌표와 산림의 거리를 실측한 자료는 아님 |
| A/B 위치·산림 인접·국소 H3·경로 상태 | 명시적인 합성 촬영 조건. 기관 관측·예측·대피명령으로 표현하지 않음 |
| 참고 경로 | 표시용 선, `operational_use=false`; 통제 상태 A에는 선을 제공하지 않음 |

원문 출처 시각은 보존한다. 일자만 있는 발표는 해당 날짜 마지막 시각을 보수적 상한으로, 일자 자체가 없는 지침은 열람 시각을 이용 가능 시각 상한으로 저장한다. 정확한 원시 관측시각으로 주장하지 않는다. 재생의 `observed_at`과 `expires_at`은 실행 시점에 별도로 생성한다.

## 화면과 개인 상태

- 오늘의 행동요령은 유효한 위치가 지역 조건 안에 있고 근거가 유효할 때만 제공한다. 산림 인접과 건조 조건이 함께 있을 때 산불 주의, 안개 관측이 확인됐을 때만 안개 주의를 제공한다. 개인 대응 정책의 긴급 행동을 홈 날씨 카드에 재사용하지 않는다.
- 나의 사전 준비는 위 공통 준비 1개, 아래 개인 준비 1개다. A는 어린이 비상용품, B는 이동 보조기구 준비가 표시된다.
- 사전 프로필의 어린이는 현재 동행을 뜻하지 않는다. A에게 현재 아이 동반을 질문하고 답변을 확인한 뒤 `child_present=true`를 저장한다.
- 보조기구 사용은 이동불가를 뜻하지 않는다. B의 혼자 있음과 이동 가능은 답변과 명시적 확인 후 저장한다.
- A 위급은 별도 현장 조건과 탈출 경로 불가에 따른다. B 대피는 같은 국소 조건에서 이동 경로를 이용할 수 있는 설정에 따른다. 이름·보호 대상만으로 단계를 지정하지 않는다.
- 화면의 ‘시연’ 문구는 제거한다. 내부 `mode/origin/operational_use`, 출처·자료 기준일, 실제 통행 확인이 필요한 참고 경로의 의미는 보존한다.
- 새 공식 경보는 전경 갱신 루프로 앱 배너를 표시한다. 이미 권한이 있는 Android는 로컬 알림을 한 번 요청한다. Firebase 원격 푸시나 종료된 앱 수신 성공을 의미하지 않는다.

## 재생 명령

일반 서버의 기존 API 컨테이너에서 실행한다. 비공개 상태 파일에는 테스트 계정 토큰이 들어가므로 `/accounts` 아래 권한 600으로만 저장하고 Git·채팅에 복사하지 않는다. 기본 실행은 새 시나리오와 A/B 계정을 만들며 기존 사용자 데이터를 지우지 않는다.

```sh
python tools/filming_scenario.py prepare --state /accounts/filming-run.json
python tools/filming_scenario.py trigger --state /accounts/filming-run.json
python tools/filming_scenario.py verify --state /accounts/filming-run.json
```

`all`은 위 세 단계를 순서대로 수행한다. `prepare`는 공식 자료 임베딩 저장→분석 큐의 검색→지역 조건 저장과 홈 카드 준비까지 진행한다. `trigger`는 긴급 큐의 공식 기록과 분석 큐의 같은 사건 자료를 넣고 Qwen 사건 통합을 기다린다. `verify`는 A/B 실제 Qwen 텍스트 답변, 확인 전 상태 불변, 확인 후 저장·정책 갱신, A 경로 숨김/B 참고 경로를 확인한다. 결과 요약은 상태 파일과 같은 위치의 `.report.json`에 생성하며 원문 발화·사용자 ID·토큰은 제외한다.

기존 휴대폰에 역할을 준비할 때는 운영자가 대상 계정을 정확히 확인한 뒤 `prepare --scenario mobile-demo --phone-user <확인한 계정> --phone-role A`를 사용한다. 이 명령은 그 계정의 촬영용 프로필과 합성 위치를 바꾼다. 실제 GPS를 수집하지 않는다. A/B 위치는 서로 다르므로 촬영 중 앱의 기본 위치 설정 버튼으로 덮어쓰지 않는다. 위치·현재 상태의 기본 만료는 5분이며 각 실행 단계에서 위치를 새로 입력한다.

## 검증 상태

출처/시간 정밀도·관측하지 않은 안개 미제공·사전 정보와 현재 동반 상태 구분에 대한 자료 계약 검사 3개를 통과했다. 전체 서버 회귀, 일반 서버 배포와 실모델 파이프라인 실행은 진행 중이다. 실제 예측·학습·119 연락·GPS·Firebase 발신은 변경하지 않는다.
