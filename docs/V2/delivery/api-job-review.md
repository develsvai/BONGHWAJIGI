## 이번 문서에서 구체화한 제안

경로 `/v1`, Bearer 인증 경계, 리소스 revision, 오류 형식, 멱등 키, UTC와 GeoJSON, long polling 및 push 조합, 5km 주변 반경, 달력 3개월 기준, 위치 300초/100m, 상태 60분, cursor/멱등 기록 24시간을 초안으로 제시했다. 이런 구현 선택을 검증된 재난 임계값이나 팀 승인으로 표현하지 않는다.
