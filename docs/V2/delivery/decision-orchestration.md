# 자료 분석과 개인 안내 갱신 연결

2026-11-01 KST. 초기 Loom 계획의 산출물 경로를 현행 산불 MVP의 구현·검증 기록에 연결하는 완료 근거입니다. 아래 링크의 상세 문서·코드·보고서를 정본으로 사용합니다. 이번 상태 정리에서 서비스 배포나 모델 실행을 새로 수행하지 않았습니다.

현행 연결은 수신 API→DB/outbox→분석큐→저장문서·인터넷뉴스→GPU임베딩·pgvector검색→Qwen자료정리→사건/위치/프로필/확인상태/DB지침→개인정책revision→앱변경조회입니다. 공식 원문은 독립 urgent경로로 먼저 전달합니다. 실제 예측은 연결하지 않았습니다.

새 자료·정정/해제·위치·프로필·확인상태·지침 버전과 주기적 만료 점검이 재평가를 요청합니다. 결과 해시가 바뀔 때만 새revision과 변경 기록을 만들고 늦은 Qwen결과·역순 입력이 최신 상태를 덮지 않게 합니다. 단계가 같아도 행동이 바뀌면 갱신합니다.

앱은 인증된 변경 cursor/revision과 최대25초 wait를 사용합니다. 현재모의푸시·전경조회와 실제백그라운드FCM의 경계를 유지합니다. 상세 근거는 [개인정책 루프](personal-policy-loop.md), [현재 API](mvp-app-api.md), [실행 변경조회](../../../src/bonghwajigi/api/mobile.py), [루프·실패 경계 시험](../../../tests/test_policy_loop.py), [촬영 완료 결과](filming-scenario-pipeline.md)입니다.
