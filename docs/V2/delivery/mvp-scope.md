# 현행 산불 MVP 범위

2026-11-01 KST. 초기 Loom 계획의 산출물 경로를 현행 산불 MVP의 구현·검증 기록에 연결하는 완료 근거입니다. 아래 링크의 상세 문서·코드·보고서를 정본으로 사용합니다. 이번 상태 정리에서 서비스 배포나 모델 실행을 새로 수행하지 않았습니다.

- 재난은 산불, 단계는 1 경고·2 대피·3 위급입니다. 공식 기관 경보와 개인 단계는 별도입니다.
- Tailnet 안의 일반 서버 API·DB·긴급/분석 큐와 GPU Qwen·Embedding을 사용합니다.
- 자료는 확보한 공식 과거 기록·검색 자료·합성 조건을 수신 API로 재생합니다. K8s 상시 수집은 실행하지 않습니다.
- 실제 예측은 unavailable/null, FCM은 모의 전달입니다. 서버 음성·3D·실제 안전 경로·자동119 신고는 제공하지 않습니다.
- 기존 세 사용자 재생과 후속 A/B 촬영은 서로 다른 검증이며, 후속 촬영은 사후 기후분석도 포함합니다. 당시 공개 자료만으로 한 예측 백테스트가 아닙니다.
