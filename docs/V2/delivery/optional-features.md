# 현재 MVP의 선택·제외 기능 경계

2026-11-01 KST. 초기 Loom 계획의 산출물 경로를 현행 산불 MVP의 구현·검증 기록에 연결하는 완료 근거입니다. 아래 링크의 상세 문서·코드·보고서를 정본으로 사용합니다. 이번 상태 정리에서 서비스 배포나 모델 실행을 새로 수행하지 않았습니다.

| 기능 | 현재 범위 |
| --- | --- |
| 3D 지도 | MVP 제외. 기존 구성/아이디어를 구현 완료로 표시하지 않음 |
| 2D 배경 지도 | 검증 앱의 NAVER Maps 표시. 서버가 실제 안전 대피 경로를 검증한 것은 아님 |
| 표시용 경로 | 명시적인 합성 경로와 차단·이탈·정보부족 숨김 계약. 실제 통행·무장애 접근성·대피소 안전 미검증 |
| 서버 STT/TTS·오디오 | 제외. 서버는 텍스트 제공 |
| 단말 음성 | 후속 채택한 기기 음성 인식·읽기. 서버로 텍스트를 전달하고 사용자 확인 후 상태 반영 |
| 119 | 단말 연결도 사용자 확인·OS영역. 시연에서 실제 연락·자동 신고하지 않음 |

[현재 앱 계약](mvp-app-api.md), [대화·경로 경계](mobile-dialogue-and-route.md), [단말 후속 검증](mobile-submodule-deployment.md), [촬영 검증](filming-scenario-pipeline.md)이 근거입니다. 별도 채택되지 않은 서버 음성·실제 경로의 포괄 구계약은 현재 백로그에서 제거했습니다. 새 기능을 구현할 때는 구체적인 자료·안전·API·검증 계약을 다시 정합니다.
