# 실기기 위치·현재 상태의 시계 오차 보정

2026-11-01 KST. Samsung 실기기의 합성 위치 버튼 요청이 HTTP 422로 거절되는 문제를 확인했다. 같은 시점에 읽은 단말 시계는 로컬 측정 중간값 대비 +0.618초, NTP 동기화 일반 서버는 +0.015초였다. 단말이 약 0.603초 앞서 있었고, 기존 API는 서버보다 조금이라도 미래인 `captured_at`·`observed_at`을 거절했다.

## 변경 계약

- 위치 `PUT /v1/me/location`과 현재 상태 `PUT /v1/me/responses/{response_id}/context`에 동일한 시간 검증을 적용한다.
- 서버 평가 시각보다 30초 이내로 앞선 단말 입력은 서버 평가 시각으로 보정한다. 정책용 관측시각과 만료시각은 각각 보정된 시각 및 그로부터 5분이다.
- 30초 초과 미래와 5분 초과 과거는 기존 `LOCATION_TIME_INVALID`·`CONTEXT_TIME_INVALID` 422 응답을 유지한다.
- 위치 원본의 단말 시각은 보존하여 순서 검증과 같은 fix ID의 멱등성을 유지한다. 삭제 후에도 마지막 단말 시각만 남겨 이전 위치 재전송이 위치를 복원하지 못하게 한다. 좌표를 삭제 tombstone에 남기지 않는다.
- API 필드·OpenAPI·DB migration·대응 단계 기준은 변경하지 않는다.
