# 예측 목표와 현재 제공 경계

2026-11-01 KST. 초기 Loom 계획의 산출물 경로를 현행 산불 MVP의 구현·검증 기록에 연결하는 완료 근거입니다. 아래 링크의 상세 문서·코드·보고서를 정본으로 사용합니다. 이번 상태 정리에서 서비스 배포나 모델 실행을 새로 수행하지 않았습니다.

실제 사용자에게 검증된 산불 영향 확률을 제공하는 모델은 아직 채택하지 않았습니다. 현재 앱은 unavailable/probability=null을 반환하며 개인 대응은 공식 근거·사용자 상태·검토된 규칙으로 결정합니다.

연구 목표는 서로 구분합니다.

- NDWS 초기 일별 위성 관측과 국내 GK2A 미래1·3·6시간 화재 관측은 실제 화선 도달·신체 피해가 아닙니다.
- GOFER 접근 연구는 재구성 경계가 연구 반경2km 안에 처음 접근하는 시간·구간이며2km는 안전 거리 기준이 아닙니다. 미관측/검열을 보존합니다.
- ELMFIRE 가정 조건의 도달 시나리오 비율은 보정된 개인 위험 확률이 아닙니다.

자료·목표·분할·평가·판본과 한계는 [학습 README](../../../training/README.md), [국내 개선 기록](korea-wildfire-improvement.md), [GOFER 고정 계획](../../../training/reports/approach-pilot-20261101/gofer/plan.json)에 있습니다. 개인 이동 능력을 환경 확률의 학습 입력으로 섞지 않습니다. 국내 실제 화선·연료·당시 예보·독립 접근 정답 및 채택 판정은 새 대기 계약으로 분리합니다.
