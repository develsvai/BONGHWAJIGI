# 재난 데이터 수집 카탈로그와 구룡마을 사례

기준일: 2026-10-30, Asia/Seoul. 대상 독자는 코디세이 해커톤의 데이터 수집 담당자와 모델·앱 연결 담당자입니다.

## 전달 내용

XLSX에는 35개 국내외 데이터 항목, 연결 예제 10개, 사건 타임라인 13개 기록, 사례별 수집 상태, 서울 기상 일자료 2행, Sentinel 제품 메타데이터 9행, HTTP·해시 수집로그와 공통 데이터 규약이 들어 있습니다. CSV는 XLSX와 같은 내용을 UTF-8 BOM으로 제공합니다. 컬럼의 미검증 표기는 명세나 실제 응답을 확인하지 못했다는 뜻이며, 완성된 운영 API 목록이라는 뜻은 아닙니다.

## 실제 확보 결과

- NASA FIRMS의 MODIS, S-NPP VIIRS, NOAA-20 VIIRS, NOAA-21 VIIRS 전지구 최근7일 CSV를 내려받았습니다. 각각 74,400 / 414,040 / 427,290 / 397,898행이며 UTC 날짜 범위는 2026-10-23~30입니다.
- 사례 검색은 KST 2026-10-27 00:00 이상, 10-29 00:00 미만과 경도127.04~127.09, 위도37.46~37.50의 사각형을 사용했습니다. 이 영역은 연구용 검색영역이며 공식 화재경계나 정확한 발화점이 아닙니다. 4개 자료 모두 검색 결과 **0건**입니다. 구름·화재 크기·통과 시점 중 무엇이 원인인지 이번 자료만으로 판단할 수 없습니다.
- 같은 KST기간에 한국 주변의 넓은 대조영역(경도124~132, 위도33~39)에서는 각각9 / 128 / 165 / 77건을 확인했습니다. 이 영역은 대한민국 행정경계가 아니며 북한·인근 해역 등을 포함합니다. `FIRMS_국내주변광역_샘플.csv`는 그 379행을 센서 식별값과 함께 제공합니다. 독립 화재379건이 아닙니다.
- Copernicus CDSE OData에서 UTC 10월25일00시~30일00시와 위 검색영역을 교차 검색해 Sentinel-2 2제품, Sentinel-1 7제품의 메타데이터를 확보했습니다. S2 L1C/L2A는 같은 촬영의 다른 처리단계입니다. S1은 RAW/SLC 등의 제품을 포함하며 모두 즉시 판독 가능한 지도 영상은 아닙니다. 원영상 픽셀을 내려받거나 피해를 판독하지 않았습니다.
- Sentinel-2의 ContentDate 시작은 10월28일02:18:09 UTC(11:18:09 KST)이며, L2A 공개는05:09:20 UTC(14:09:20 KST)입니다. 관측 후 공개까지 약2시간51분입니다. 이 촬영은 완진 보도시각 이후입니다. 타일별 실제 촬영시각과 데이터테이크 시작시각 차이는 영상 내 메타로 추가 확인해야 합니다.
- 기상청 날씨누리 서울108 지점에서 일자료를 확보했습니다. 10월27일 평균/최고/최저기온은11.3/16.2/7.0℃, 28일은7.9/14.1/3.7℃입니다. 강수 원문 `-`는 숫자0으로 바꾸지 않았습니다. 서울 관측소 값은 구룡마을 현장값이 아닙니다. 시간별 풍향·풍속·습도는 미수집입니다.
- ASOS 시간자료 API는 무키 요청에 HTTP401 `SERVICE_KEY_IS_NULL`을 반환했습니다. NOAA 서울 연파일 URL은 HTTP200이지만 HTML이어서 관측 CSV로 인정하지 않았습니다.
- USGS의 한국 주변 지진 조회는 정상 GeoJSON `count=0, features=[]`를 반환했습니다. 이는 별도의 연결 예시이며 화재 검증 자료가 아닙니다. GDACS RSS도 수집했지만 RSS만으로 사건 과거 전체 이력을 검색했다고 볼 수 없습니다.

## 공식 사건 기록의 범위

[강남구 10월30일 발표](https://gangnam.go.kr/board/B_000031/1075546/view.do?mid=ID01_0313)는 10월27일 화재, 구호대상91가구127명, 개포중·구룡중 임시대피소 운영을 확인하는 공식 출처입니다. 발표 속 10월29일13시 기준 거주현황(70가구111명)은 별도 시점·모집단입니다.

[서울시 10월27일 게시](https://www.seoul.go.kr/news/news_report.do?nttNo=468977)의 제목·등록일·첨부링크를 확인했습니다. 첨부 HWP 본문은 미수집입니다. 소방청·강남소방서 원본 상황일지나 직접 발표문, 행안부 공식 재난문자 원문·발송시각·SN은 확보하지 못했습니다. 언론이 인용한 문자 내용을 공식 원문 수집으로 계산하지 않았습니다.

[뉴시스 10월27일 현장브리핑 보도](https://nwww.newsis.com/view/NISX20261027_0003843536)와 [10월28일 후속보도](https://www.newsis.com/view/NISX20261028_0003844176)를 보조 근거로 사용했습니다. 대응1단계 시각은15:59와15:49가 기사별로 다르고, 주불진압은 [조선일보 보도](https://chosun-chosun-prod.cdn.arcpublishing.com/national/national_general/2026/10/27/7CQPX457BZA27GOCASAPQ4IJBA/)의23:20과 뉴시스의다음날02:21이 다릅니다. 원본 소방기록을 확보하기 전 확정값으로 합치면 안 됩니다. 완진04:39는 보도 간 일치하지만 출처 성격은 여전히 언론 인용입니다.

구룡마을 사례는 마을 내 가건물 밀집 화재입니다. 산림 산불 모델의 확산 정확도를 검증하는 정답 자료로 일반화하지 말고, 수집·시간순 재구성·경보·대피시설 연결 가능성을 검토하는 사례로 사용하십시오.

## 대신 다운로드할 수 있는 범위와 팀의 연결 작업

공개 무키 파일과 API는 대신 다운로드·정리할 수 있으며 이번에 실제 수행했습니다. 모든 API를 먼저 앱에 붙일 필요 없이 이 파일과 공개 샘플로 모델팀과 필드·단위·시간 기준부터 합의할 수 있습니다.

행안부·기상청·산림청 등 승인키 자료는 팀 계정으로 활용신청하고, 승인된 키를 서버의 비밀설정에 넣은 뒤 연결해야 합니다. 키를 채팅·엑셀·모바일 소스에 넣지 마십시오. 회원가입이나 동의가 필요한 위성 원영상도 해당 계정·토큰이 필요합니다. 이 산출물은 일회성 수집 결과이며, 계속 갱신되는 운영 수집기는 별도 작업입니다.

팀 연결 범위는 다음과 같습니다.

1. 공식 문자·관측·예보·발생통계·시설/통제 P0 자료의 키와 이용조건 확보.
2. 페이지 전체 수집, 재시도·호출량 제어, 중복제거, 원본·해시·버전 보존.
3. observed_at / issued_at / valid_at / collected_at 분리. 위성UTC와 국내KST 정규화.
4. 지도 좌표계·행정구역·시설 운영상태 대조 후 모델팀에 JSON/CSV/GeoJSON 전달.
5. 관측과 예보를 구분하고, 과거 재현 때 당시 이용 가능했던 발행본만 사용. 뒤늦은 수정본·재분석을 사용하면 별도 표시.

확산모델·예측엔진 개발은 이번 작업에 포함하지 않았습니다. 지도 일반경로, 해외 위성 열이상, 광역 기상예보만으로 안전한 대피로를 확정할 수 없습니다. 공식 대피 지시·현장 통제·대피소 개방상태를 우선 연결하십시오.

## 연결 예제의 주요 출처

- [행안부 긴급재난문자 최신 서비스](https://www.safetydata.go.kr/disaster-data/view?dataSn=228): V2 `DSSP-IF-00247`, `serviceKey`, `returnType`, `pageNo`, `numOfRows`, `crtDt`, `rgnNm`. 과거 `DisasterMsg2`를 새 서비스로 오해하지 마십시오. `crtDt`는 시작일이며 응답 날짜 종료필터·페이지 전체 순회가 필요합니다.
- [공식 API 대체 안내](https://www.safetydata.go.kr/common/popup_20241028.html): 회원가입·활용신청·관리자 승인 필요.
- [기상청 ASOS 시간자료](https://www.data.go.kr/data/15057210/openapi.do), [API허브](https://apihub.kma.go.kr/).
- [FIRMS Area API](https://firms.modaps.eosdis.nasa.gov/api/area/): 무료 MAP_KEY, 요청일수1~5, source 가용기간 확인. 최근7일 정적 CSV와 인증 방식이 다릅니다.
- [CDSE OData 문서](https://documentation.dataspace.copernicus.eu/APIs/OData.html): 카탈로그 검색과 원영상 다운로드의 인증 수준을 구분하십시오.
- [ECMWF Open Data](https://www.ecmwf.int/en/forecasts/datasets/open-data): 2026-10-20부터 IFS0.1° 추가, 최근12회 순환보존. 재현용 과거예보는 수집 당시 보존 필요.

## 상태·이용조건

`미수집`: 대상 원자료가 없는 상태. `미검증`: 명세·응답·기간·조건 등을 확인하지 못한 상태. `0건`: 정상 자료·기간·필터를 검사한 뒤 해당 결과가0인 상태. 빈 건수는 미확보이며0이 아닙니다.

공공기관 제공 데이터라도 모두 같은 이용조건은 아닙니다. 공유플랫폼 상세 화면의 공공누리3유형 안내와 외부 포털의 표기가 다를 수 있으므로 최신 데이터별 허가를 확인하십시오. 무료는 무조건 가공·재배포 가능하다는 뜻이 아닙니다. 원문 문자는 수정하지 않고 별도 파생필드로 분류하는 설계를 권합니다. 언론 본문·사진은 이 패키지에 재배포하지 않았습니다.

## 재현·파일 구성

CSV 날짜/시각은 시간대를 붙인 원문형식입니다. XLSX의 UTC 열은 표시 형식을 지정한 날짜값이며 시간대 변환을 자동 수행하지 않습니다. 사건 타임라인의 날짜만 있는 기록은 시각 미상으로 유지했습니다. 웹 문헌 확인만 한 일부 기사는 세부 수집시각이 없음을 표시했습니다. 수집로그의 시각은 요청을 시작한 시각이며 응답 수신 완료시각은 별도로 측정하지 않았습니다. 같은 대상을 다시 내려받은 경우 최종 보관 응답의 기록을 남겼습니다.

ZIP의 `raw/`에는 NASA 공개 CSV4종, CDSE 응답2종, USGS·GDACS 응답, 기상청 일자료 HTML, 행안부 명세, 지자체 공개게시 HTML 등을 넣었습니다. `수집로그.csv`와 `수집로그.json`의 SHA256으로 요청별 원본을 대조할 수 있습니다. FIRMS는 최근 파일이 계속 교체되므로 같은 URL을 나중에 호출해도 동일 내용이 나오지 않습니다. 이번 보관본을 기준으로 재현하십시오. 원본은 ASCII 파일명으로 보관되어 있으며 ID와 출처 URL은 수집로그에서 연결됩니다.
