# 산불 MVP 범위와 기능

기준: 2026-11-01 구현·검증 기록. 문서 정리: 2026-11-02.

- 재난은 산불, 단계는 1 경고·2 대피·3 위급입니다. 공식 기관 경보와 개인 단계는 별도입니다.
- Tailnet 안의 일반 서버 API·DB·긴급/분석 큐와 GPU Qwen·Embedding을 사용합니다.
- 자료는 확보한 공식 과거 기록·검색 자료·합성 조건을 수신 API로 재생합니다. K8s 상시 수집은 실행하지 않습니다.
- 실제 예측은 unavailable/null, FCM은 모의 전달입니다. 서버 음성·3D·실제 안전 경로·자동119 신고는 제공하지 않습니다.
- 기존 세 사용자 재생과 후속 A/B 촬영은 서로 다른 검증이며, 후속 촬영은 사후 기후분석도 포함합니다. 당시 공개 자료만으로 한 예측 백테스트가 아닙니다.

## 선택·제외 기능

| 기능 | 현재 범위 |
| --- | --- |
| 3D 지도 | MVP 제외. 기존 구성/아이디어를 구현 완료로 표시하지 않음 |
| 2D 배경 지도 | 검증 앱의 NAVER Maps 표시. 서버가 실제 안전 대피 경로를 검증한 것은 아님 |
| 표시용 경로 | 명시적인 합성 경로와 차단·이탈·정보부족 숨김 계약. 실제 통행·무장애 접근성·대피소 안전 미검증 |
| 서버 STT/TTS·오디오 | 제외. 서버는 텍스트 제공 |
| 단말 음성 | 후속 채택한 기기 음성 인식·읽기. 서버로 텍스트를 전달하고 사용자 확인 후 상태 반영 |
| 119 | 단말 연결도 사용자 확인·OS영역. 시연에서 실제 연락·자동 신고하지 않음 |
