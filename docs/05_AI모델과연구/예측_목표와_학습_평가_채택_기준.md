# 예측 목표와 학습·평가·채택 기준

기준: 2026-11-01 구현·검증 기록. 문서 정리: 2026-11-02.

실제 사용자에게 검증된 산불 영향 확률을 제공하는 모델은 아직 채택하지 않았습니다. 현재 앱은 unavailable/probability=null을 반환하며 개인 대응은 공식 근거·사용자 상태·검토된 규칙으로 결정합니다.

연구 목표는 서로 구분합니다.

- NDWS 초기 일별 위성 관측과 국내 GK2A 미래1·3·6시간 화재 관측은 실제 화선 도달·신체 피해가 아닙니다.
- GOFER 접근 연구는 재구성 경계가 연구 반경2km 안에 처음 접근하는 시간·구간이며2km는 안전 거리 기준이 아닙니다. 미관측/검열을 보존합니다.
- ELMFIRE 가정 조건의 도달 시나리오 비율은 보정된 개인 위험 확률이 아닙니다.

자료·목표·분할·평가·판본과 한계는 [학습 README](../../training/README.md), [국내 개선 기록](국내_산불_예측_모델_개선_실험_기록.md), [GOFER 고정 계획](../../training/reports/approach-pilot-20261101/gofer/plan.json)에 있습니다. 개인 이동 능력을 환경 확률의 학습 입력으로 섞지 않습니다. 국내 실제 화선·연료·당시 예보·독립 접근 정답 및 채택 판정은 새 대기 계약으로 분리합니다.

## 학습 자료의 실제·합성·미관측 구분

[초기 실제 자료 구축](XGBoost_학습_데이터_확보와_구성.md), [학습 README](../../training/README.md), [자료·분할·품질 및 실험 기록](국내_산불_예측_모델_개선_실험_기록.md)에 재현 경로를 보존합니다.

- 실제 NDWS·GOES·GK2A 관측, GOFER 경계와 기상/지형 입력은 각각 출처·단위·시각·판본·권리·해시·가공 내역으로 구분합니다.
- 실제 관측의 train/validation/test와 연구별 사건·기간 분할을 보존하고, 미래 미관측·구름·누락을 비도달0으로 채우지 않습니다.
- 합성 CUDA 연결 시험·물리 확산 시나리오는 별도 simulation 산출물입니다. 실제 자료와 섞어 성능을 주장하지 않습니다.
- 국내 첫 관측 재구축 및 GFS2022 비교는 모집단·시점이 다르며 이전 표와 단순 전후 비교하지 않습니다.
- 국내2025 holdout의 기존 미열람 조건과 source_asof 미검증 한계를 유지합니다.

현재 확률의 운영 타당성은 미입증입니다. 국내 실제 접근 정답·화선·당시 가용 입력의 보강은 대기 작업이며, 자료 구축 완료가 실제 개인 예측 연결 완료를 뜻하지 않습니다.

## 학습 실행과 저장 검증 근거

[GPU 설치·합성 CUDA 연결](Qwen과_XGBoost_설치와_사용법.md), [실데이터 실행기](XGBoost_학습_실행_방법.md), [사용자가 실행한 CUDA 학습의 독립 재추론](최초_CUDA_학습과_저장_모델_검증.md)이 완료 기록입니다.

실제 NDWS 학습은 저장 모델·데이터·피처 순서·트리 수·검증 및 최초 독립 test 평가를 재현했습니다. 이후 국내 관측·GOFER·GFS 개선 연구는 [개선 기록](국내_산불_예측_모델_개선_실험_기록.md)과 [학습 README](../../training/README.md)에 별도 분할·고정 계획·영수증·모델 SHA·재로딩·성공/실패 결과를 보존합니다.

최신 [GFS 비교 검증](../../training/reports/korea-gfs-2022-20261101/verification.json)은45회 적합과 독립 수치 대조·전체542개 훈련 시험 통과를 기록합니다. 이는 과거 실행 근거이며 이번 Loom정리에서 재학습한 결과가 아닙니다. 연구 실행은 종료됐고 실서비스 모델·단계·알림을 바꾸지 않았습니다. 일반 서버 실제 CPU 모델 채택·교체·복구는 별도 대기 범위입니다.

## 평가 결과와 실제 연결 보류

현재 판정은 **국내 개인 대응용 실제 확률 연결 보류**입니다. 연구의 일부 순위 지표 개선을 운영 확률의 타당성으로 해석하지 않습니다.

- [초기 CUDA 모델 독립 평가](최초_CUDA_학습과_저장_모델_검증.md)는 미국 위성 관측 목표에 대한 결과이며 국내 사용자 영향 성능이 아닙니다.
- [보강 실험](../../training/reports/model-strengthening-20261101/README.md), [국내 첫 관측 비교](../../training/reports/korea-first-observation-20261101/README.md), [GFS2022 비교](../../training/reports/korea-gfs-2022-20261101/README.md)는 기간·사건 분할, 기준선 대비 실패 지표와 보정 한계를 보존합니다.
- 최근 GFS 후보는 기존 입력·거리 기준 대비 채택하지 않았습니다. 화재 관측/재구성 경계·실제 화선·개인 피해·연기/경로 노출은 서로 다른 목표입니다.
- ELMFIRE 가정별 scenario_fraction을 검증된 확률로 변환하지 않습니다. source_asof·연료·국내 독립 정답의 공백을 유지합니다.

현재 API의 unavailable/null과 공식 경보 독립 전달은 [현재 앱 계약](../03_API와앱연동/현재_앱_API_실행_계약.md), [정책](../01_서비스와설계/대응_3단계와_개인별_정책.md)에 있습니다. 국내 정답·당시 입력 확보와 독립 평가·보정 후 재판정은 새 대기 태스크, 채택 모델의 CPU 연결·되돌리기는 기존 대기 태스크로 유지합니다.
