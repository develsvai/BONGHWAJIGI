# 봉화지기 설계 문서 안내

기준일은 2026년 10월 30일입니다. 현재 대화에서 정리한 요구사항과 같은 날 해커톤 회의 전사의 내용을 보존하며, 팀원의 UI/UX가 도착한 뒤 구현 범위를 결정하는 데 사용합니다.

봉화지기는 빠르게 들어온 재난 정보를 사용자 위치와 연결하고, 사용자에게 지금 필요한 행동을 안내하는 서비스입니다. 핵심은 다중 출처 정보의 신속한 처리, 주변 지역에서 오는 영향의 평가, 개인 상황에 맞는 대응입니다.

## 상태 표기

- **요구사항:** 사용자가 대화에서 직접 제시하거나 명확히 설명한 조건입니다.
- **회의 방향:** 전사에서 확인되는 제안 또는 반복된 방향입니다. 전사만으로 모든 참석자의 최종 합의를 단정하지 않습니다.
- **설계 제안:** 요구사항을 구현하기 위해 구체화한 방안입니다. 기술 선정이나 정책 승인을 의미하지 않습니다.
- **미결정:** UI/UX, 데이터 확보, 성능 검증 또는 팀 논의를 거쳐 정할 항목입니다.

문서에 적힌 모델, 화면 이름, 데이터 필드, 대응 단계는 별도 표기가 없는 한 설계 제안입니다. 실제 재난 대응 정책과 수치 임계값은 확정되지 않았습니다.

## 현재 우선순위

1. 팀원의 UI/UX를 수령하고 [인계 항목](V1/ui-ux-handoff.md)과 대조합니다.
2. 시연할 재난, 지역, 실내·실외 범위와 음성 대화 포함 여부를 결정합니다.
3. 실제 확보 가능한 데이터와 갱신 지연을 확인하고 화면별 데이터 계약을 정합니다.
4. LLM 사용 범위를 확정한 뒤 모델·API·앱 구현을 진행합니다.

## 근거와 보관 범위

회의 근거는 `26-10-30_해커톤_회의_5_전사.txt`입니다. 길이 01:32:30의 전사에 불확실 구간 80개가 표시되어 있습니다. 이 문서 묶음은 텍스트 대조 결과이며, 원음 재검증 결과가 아닙니다. 구간별 근거는 [회의 대조 문서](V1/decisions-and-meeting-review.md)에 남겼습니다.

회의 전체 전사와 개인별 발언은 복제하지 않습니다. 서버 계정, 비밀번호, VPN 정보, API 키도 문서에 포함하지 않습니다. 과거 지하철 아이디어와 KOSIS 탐색은 아이디어 발굴 배경이며, 현재 서비스의 구현 요구사항으로 이관하지 않습니다.
