## 설계를 읽을 때의 주의점

- 공식 자료라는 이유만으로 항상 최신이고 정확하다고 가정하지 않습니다. 정정·충돌·지연을 보존해야 합니다.
- 회의의 여러 출처 비교라는 표현은 머신러닝 평가의 교차검증과 구분합니다. 출처 비교만으로 확률 모델의 성능 검증이 끝나지 않습니다.
- 자료를 비교해 앱의 대응 상태를 정하는 것과 공식 기관의 경보를 발령하는 것은 다른 역할입니다.
- 3D 표시 가능성과 실제 안전 경로 확보 가능성은 별도입니다. 공간 데이터와 통제·대피 장소 정보가 필요합니다.
- 전사 중 기존 기관 사업, 해외 사고 사례, API 확보 발언은 사실 확인이 완료된 서비스 자원으로 옮기지 않았습니다.
- 과거 지하철·탄소 행동·다른 AI 아이디어는 현재 재난 서비스 범위에 추가하지 않았습니다.
