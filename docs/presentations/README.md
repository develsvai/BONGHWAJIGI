## 조립과 수정

1. 원본 템플릿을 복사해 통합 발표자료를 만듭니다.
2. `slides`의 한 장짜리 파일을 필요한 위치에 삽입합니다. PowerPoint에서 기존 서식을 유지하고, Mac의 Keynote에서는 가져온 뒤 배치를 확인합니다.
3. 각 슬라이드의 발표자 노트에 있는 발표 멘트·출처·확인 범위를 함께 확인합니다.
4. 데이터 활용 및 파이프라인 설계 2~3장은 추가 작성 예정입니다. 목업 페이지의 전체 발표 내 번호는 설계 분량이 확정된 뒤 정합니다.
5. 수정본은 파일명을 구분해 추가하고, 이 README와 [상위 문서 안내](../README.md), [저장소 README](../../README.md)의 안내도 함께 갱신합니다.

## 자료 해석

- 구룡마을 사례는 가건물 밀집 지역의 도시화재이며 산림 산불 사례가 아닙니다. 산불 MVP의 문제 제기에 활용합니다.
- 지도 화살표는 소방 브리핑을 인용한 보도의 방향 개요입니다. 실제 화선·피해 경계·확산 거리·검증된 예측 결과를 뜻하지 않습니다.
- 목업 HTML은 홍수 예시입니다. 실제 지도·음성·신고 연동 완료 또는 산불 시나리오 구현 완료를 보여주는 화면이 아닙니다.
- '예측·추천'은 서비스 목표이며, 실제 재난 대응 성능을 검증했다는 의미가 아닙니다. 상세 근거와 범위는 각 파일의 발표자 노트에 있습니다.

[manifest.json](manifest.json)에 파일 크기, 슬라이드 수, SHA-256 및 Git 파일 해시를 기록했습니다. GitHub에서 PPTX가 미리 보이지 않으면 파일 페이지의 다운로드 기능으로 내려받아 PowerPoint 또는 Keynote에서 여세요.
