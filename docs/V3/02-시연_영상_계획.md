# 봉화지기 2분 시연 영상 계획

상태: **촬영 전 계획** · 화면 비율: **16:9** · 목표 길이: **118초**

이 문서는 영상의 장면과 문구를 정리한다. 영상 파일이나 두 사용자용 동적 화면이 이미 만들어졌다는 뜻은 아니다. 화면 속 지역·위치·경로·단계는 시연용 데이터이며 실제 재난 안내에 사용하지 않는다.

## 보여줄 핵심

**같은 산불이어도 위치와 이용 가능한 이동 경로에 따라 개인 대응 단계가 달라지고, 사전 정보와 재난 중 확인한 답변에 따라 준비사항과 행동요령이 달라진다.** 두 휴대폰은 같은 산불 사건을 보여준다. 공식 경보와 봉화지기가 표시하는 개인 대응 단계 `대피`·`위급`은 구분한다.

단계·이유·행동요령·음성 질문은 시연 서버 데이터로 정한 결과를 화면에 표시하는 설정이다. 앱이 GPS만 보고 단계를 계산하거나 답변에서 확인되지 않은 상태를 추정하는 장면으로 만들지 않는다.

## 두 사용자 시연 설정

| 구분 | 왼쪽 A | 오른쪽 B |
| --- | --- | --- |
| 사전 입력 | `함께 대피할 보호 대상: 어린이` | `이동 능력: 보조기구 사용` |
| 홈 `나의 사전준비` | **어린이 비상용품 준비** — 아이에게 필요한 물·간식·여벌 옷을 비상가방에 챙기세요. | **이동 보조기구 점검** — 평소 사용하는 보조기구가 바로 사용 가능한지 확인하세요. |
| 같은 산불 속 위치·경로 | 영향 지역에 더 가깝고 확인된 이동 경로가 통제됨 | 안내된 경로를 이용할 수 있음 |
| 알림 직후 개인 대응 단계 | **위급** · 빨간 경보 영역 | **대피** · 주황 경보 영역 |
| 재난 중 확인할 정보 | 아이가 **지금 함께 있는지** | 보조기구를 사용해 **지금 혼자 이동할 수 있는지** |

A의 `위급`은 어린이 동반 자체가 아니라 **위치와 경로 통제**를 반영한 시연 결과다. 프로필의 `어린이`는 함께 대피할 수 있는 보호 대상에 관한 사전 입력이며, 현재 함께 있다는 사실은 A의 답변 뒤에만 표시한다. B 역시 보조기구 사용만으로 이동 불가로 간주하지 않는다. 두 사람의 실제 좌표·경로·공식 알림 시각은 촬영용 자료를 검증한 뒤 넣고, 임의의 숫자를 실제 값처럼 표시하지 않는다.

## 118초 장면표

| 시간 | 화면·편집 | 음성·화면 문구 |
| --- | --- | --- |
| 00:00–00:08 | 휴대폰 한 대의 `내 정보 입력` 화면. 이용 동의 항목은 이미 확인한 상태에서 핵심 입력 영역을 보여준다. | 자막: `재난 전에 내 상태를 설정합니다` |
| 00:08–00:22 | 화면이 좌우 두 휴대폰으로 갈라진다. A는 `어린이`, B는 `보조기구 사용`을 선택하고 각각 `저장`을 누른다. | 좌우 이름표 `A · 어린이와 함께 대피할 수 있음`, `B · 보조기구 사용` |
| 00:22–00:34 | 두 홈 화면으로 이동한다. 같은 화면 구조를 유지해 이후의 카드 차이가 잘 보이게 한다. | 자막: `설정한 상태에 따라 준비할 일을 보여줍니다` |
| 00:34–00:49 | 두 화면의 `나의 사전준비` 카드를 차례로 확대한다. A는 어린이 비상용품, B는 이동 보조기구 점검을 표시한다. | 카드 제목과 한 줄 설명을 읽을 수 있을 만큼 유지한다. |
| 00:49–01:05 | 알림음은 **한 번만** 울린다. 같은 산불 알림을 두 화면에 표시하고 긴급 대응으로 진입한다. 같은 2D 산불 영역에 서로 다른 내 위치와 경로 상태를 보여준다. A는 `위급 산불 발생`, B는 `대피 산불 발생`. | 자막: `같은 산불 · 서로 다른 위치와 이동 경로` |
| 01:05–01:13 | B를 회색으로 낮추고 A만 원래 색으로 둔다. A의 음성 질문 한 개를 표시·재생한다. | 질문: `지금 아이와 함께 계신가요?` |
| 01:13–01:33 | A의 답변 후 `내 현재 상태`에 `아이 동반`을 추가하고 맞춤 행동요령을 갱신한다. B는 계속 음영 처리한다. | A: `지금 아이랑 있습니다.` 안내 예시: `아이와 떨어지지 마세요.` `119에 현재 위치와 아이 동반·경로 통제 상황을 알리세요.` |
| 01:33–01:39 | A를 회색으로 낮추고 B를 원래 색으로 복원한다. B의 질문을 표시·재생한다. | 질문: `보조기구를 사용해 혼자 이동할 수 있나요?` |
| 01:39–01:51 | B의 답변 후 `내 현재 상태`에 `혼자 있음`, `이동 가능`을 표시하고 맞춤 행동요령을 갱신한다. | B: `혼자라 이동할 수 있어요.` 안내 예시: `보조기구를 챙겨 안내된 안전한 경로로 대피하세요.` |
| 01:51–01:58 | 두 화면의 색을 모두 복원한다. 위쪽 단계와 아래쪽 서로 다른 행동요령을 나란히 보여주고 종료한다. | 마무리 자막: `같은 산불, 서로 다른 상황에 맞는 안내` |

질문은 **두 개이며 동시에 재생하지 않는다.** 음영은 영상 편집 효과다. 화면 안의 `실시간 음성 대화`에는 현재 서버 발화 한 개만 남기고, 새 질문이 오면 교체한다. 사용자 답변은 영상의 음성·자막으로 전달하며 앱에 채팅 이력을 새로 그리지 않는다.

## 촬영 전에 준비할 목업과 확인

1. A·B 각각의 프로필 선택, 홈 준비 카드, 지도 위치, 경로 상태, 개인 단계, 질문, 확인된 상태 태그, 행동요령을 한 사건의 **일관된 시연 데이터**로 마련한다. `나의 사전준비` 전용 API는 현재 없고 HTML 카드도 고정 예시이므로, 자동 추천이 이미 구현된 것으로 설명하지 않는다.
2. 지도는 **2D**로 표현한다. A의 통제된 경로를 안전한 대피로처럼 그리지 않고, B의 경로도 검증된 시연 자료일 때만 표시한다. GPS 위치만으로 `위급`을 판정했다고 설명하지 않는다.
3. A·B의 답변 전후에 상태 태그와 행동요령이 바뀌는 순간을 보여준다. 첫 답변은 아이 동반만 확인하며 A의 이동 가능 여부를 추정하지 않는다. 질문·단계·안내는 시연 서버 응답으로 제공된다는 설정을 유지한다.
4. 영상 바깥에 작은 `시연 화면` 표시를 두어 실제 재난 경보로 오해하지 않게 한다. 실제 119 전화·문자는 실행하지 않는다. 시연 데이터와 실제 서비스·단말 검증을 구분한다.
5. 편집본에서 전체 길이 **118초 이내**, 16:9 두 화면의 글씨 가독성, 한 번의 알림음, 두 질문의 순차 재생, 음영 전환, 마지막 비교 장면을 확인한다.

행동 문구의 공식 참고 자료는 [국민안전24 산불 국민행동요령](https://www.safekorea.go.kr/safekorea-kor/acts/nacts/action-guide.do?category=forestFires&menuSn=4)이다. 어린이와 함께 대피할 때 떨어지지 않기, 안내된 안전한 경로로 이동하기, 긴급 시 119에 도움을 요청하기를 참고했다. 위 표의 개인별 문장과 `위급`·`대피` 판정은 **영상용 예시**이므로 실제 제공 전에 시나리오 근거와 문구를 다시 검토한다.
