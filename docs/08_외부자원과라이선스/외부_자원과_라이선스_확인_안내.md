# 외부 자원과 라이선스 확인 안내

외부 자원의 이름·용도·라이선스 요약은 저장소 [README의 외부 자원 표](../../README.md#external-resources)를 기준으로 확인합니다. 이 문서는 같은 표를 다시 복사하지 않고 조사 근거의 위치를 안내합니다.

| 확인할 내용 | 조사 기록 |
| --- | --- |
| Python 패키지 이름·버전·설치 상태·라이선스 | [패키지 목록](조사기록/Python_패키지_버전과_라이선스_목록.json) |
| 직접·전이 의존성 조사 범위 | [조사 범위](조사기록/Python_패키지_조사_범위.json) |
| 데이터·콘텐츠 원천 URL과 이용 조건 | [출처 조사](조사기록/데이터와_콘텐츠_출처_조사.json) |
| 배포 메타데이터·추가 확인 | [추가 확인 2026-11-01](조사기록/라이선스_추가_확인_20261101.json) |
| Android 음성 입력·서체 자원 | [단말 음성 자원 확인](조사기록/Android_음성_자원_라이선스_확인_20261101.json) |
| 과거 외부 자원 명세의 검증 결과 | [문서 검증 기록](조사기록/외부_자원_문서_검증_기록.json) |

위 JSON은 조사 당시의 기록입니다. 실제 사용·조사 후보·미설치 자원을 구분하고, 모든 항목을 현재 사용 중이거나 최신 약관을 다시 확인한 것으로 해석하지 않습니다. 기존 장문 외부 자원 명세는 이번 정리 이전에 저장소에서 삭제된 상태였으며, 검증 기록에 남은 문서명은 당시 경로입니다.

촬영에 쓴 공식 자료별 조건은 [영덕 산불 촬영 자료](../06_시연과검증/영덕_산불_촬영_자료의_출처와_한계.md), 학습 자료의 가공·권리 범위는 [학습 안내](../../training/README.md)와 [모델 개선 실험 기록](../05_AI모델과연구/국내_산불_예측_모델_개선_실험_기록.md)을 함께 확인합니다.

사전 보유 코드는 **없음**이라는 사용자 확인을 유지합니다. 라이선스 명칭·조건·해시는 이번 문서 재배치에서 재판정하지 않았습니다.
