# HeoNey — 해커톤 아이디어 대화 정리

[공유 대화 「해커톤 아이디어」](https://chatgpt.com/share/6ae4872b-c438-83ee-940c-d2385795e0c1)를 2026년 10월 30일(KST)에 읽고 정리했다. 초기 아이디어 탐색부터 마지막 재난 대피 음성 화면 수정까지 **28차례의 문답, 사용자 발언 28개와 답변 28개**를 보존했다. 진행 안내 15개도 별도 보관했다.

최신 방향은 **같은 재난에서도 개인의 현재 상황에 따라 다른 대피 방법을 추천하는 모바일 서비스**다. 평소에는 주변 재난·안전 소식을 보여주고, 재난 시에는 재난 전용 화면에서 음성 대화로 연결한다. 마지막 사용자 요청은 원형 음성 애니메이션, 최신 발화 표시, 대화로 갱신되는 상태 박스, 화면 진입 후 자동 음성 인식과 발화 중 끼어들기다.

## 문서의 상태

- **사용자 요구:** 공유 대화에서 사용자가 직접 요청하거나 수정한 내용이다. 구현·검증이 끝났다는 뜻은 아니다.
- **답변 제안:** 대화의 ChatGPT가 제안한 방식이다. 사용자의 최종 승인이나 팀 합의를 뜻하지 않는다.
- **이전 안:** 뒤의 사용자 발언으로 수정된 초안이다. 최신 요구와 섞지 않는다.
- **미결정:** 기술·정책·데이터·디자인에서 추가 확인할 항목이다.

원문의 외부 서비스 현황, 통계, 법률 설명, 모델 성능, API 제공 범위는 당시 답변의 주장으로 보존했다. 이번 작업은 대화의 문서화이며 독립적인 사실 검증은 수행하지 않았다. 예시 대피 안내는 제품 기획용 모의 시나리오다.

첨부 이미지 3장은 파일명·크기·대화 위치 등 참조 정보만 확보했고 이미지 파일은 복원하지 못했다. 대신 이미지에 관해 사용자가 적은 요구사항과 답변에 포함된 시안 코드는 모두 보존했다. 자세한 범위는 [출처 문서](source-and-coverage.md)에 적었다.

기존 [프로젝트 설계 문서](../README.md)는 다른 대화·회의를 바탕으로 한 문서다. 이 폴더는 이번 공유 링크의 독립적인 기록이며 기존 문서의 결정을 자동으로 덮어쓰지 않는다.
