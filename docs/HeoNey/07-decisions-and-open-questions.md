# 07. 요구사항, 이전 안, 미결정

[문서 안내](README.md)

이 표의 “사용자 요구”는 공유 대화에서 직접 말한 내용이다. 그 뒤에 별도로 작성된 [모바일 화면 기획서](봉화지기_모바일_화면_기획서.md)는 최신 설계 자료로서 화면을 구체화한다. 답변의 아이디어는 팀의 최종 결정으로 승격하지 않는다.

## 방향과 변경

| 항목 | 대화에서 확인된 흐름 | 상태 |
| --- | --- | --- |
| 해커톤 주제 | 추천·정보보호 중 관점이 새로운 서비스 탐색 | 출발 조건 |
| 청년 공백 아이디어 | 경험·활동 추천에서 경험 있는 사람 추천으로 수정 | 당시 사용자 수정; 현재 앱 방향은 아님 |
| 아동 정보보호 | 게임 화면·창작물의 노출 방지 통합, 부모에게 제시 | 탐색안 |
| 외국인 지하철 | QR 진입, 사진 환승 안내, 향후 이용자 제보 | 탐색안 |
| 고령 운전 | 운전 예고편 중심, 도로 개선은 확장, 운전 대체 추천 제외 | 탐색안의 사용자 범위 조정 |
| 폭염 | 그늘길만으로 농촌 문제 해결 가능한지 의문 | 탐색안 |
| 재난 비서 | 집 안 음성 기기에서 모바일 앱으로 전환 | 후속 사용자 변경 |
| 추천의 핵심 | 같은 재난에서 개인 상태별로 대피 방법이 달라지는 점 | 현재 서비스 핵심 |
| 홈 | 주변 재난·안전 소식 조회, 긴급 알림은 GPS 기준 | 사용자 요구 |
| 재난 화면 | 재난명·영향 지역의 내 위치·공식 지시·안내 진입 | 사용자 요구 |
| 음성 화면 | 마지막 공유 대화에서는 원형 모션과 양측 발화 표시 | 공유 대화 안의 최종안; 이후 기획서에서 수정 |

## 공유 대화 답변의 설계 제안

- 공식 대피 지시와 통제정보를 경로 후보의 우선 조건으로 사용한다.
- 모델은 재난 자료의 분류·사용자 발화 이해·추천 근거 설명을 돕고, 도로망 탐색과 3D 렌더링은 별도 기능으로 나눈다.
- 이동할 수 없는 사람에게 모든 사용자와 같은 3D 경로를 강요하지 않고 긴급 지원 안내로 분기한다.
- 현재 발화로 상태가 바뀌면 저장된 기본 프로필보다 현재 상태를 우선해 추천을 다시 계산한다.
- 확인되지 않은 통행 가능성을 안전한 경로로 표시하지 않는다.
- 자동 신고나 음성 기능이 실제 연동되지 않았다면 완료한 것처럼 안내하지 않는다.

이 항목들은 안전성과 구현 가능성을 위한 답변 제안이다. 정책·기술 채택 여부는 별도 검토가 필요하다.

## 공유 대화 이후 추가된 5개 화면 기획서와의 차이

기획서에는 2026년 10월 31일 작성일과 “최신 수정사항을 우선”한다는 기준이 있다. 공유 대화의 [마지막 답변](archive/conversation-07.md#m056)은 Siri형 원형 모션·사용자 발화 박스·대피 방법 버튼을 설명하지만, 기획서는 **중앙 파형**, **사용자 발화 미표시**, **AI 발화 한 번에 하나**, **맞춤 행동요령 번호 목록**, **기본 수칙·조건부 3D·119 버튼**을 요구한다. 실제 제작 기준을 혼동하지 않도록 [기획서](봉화지기_모바일_화면_기획서.md)를 최신 화면 자료로 읽는다.

## 구현 전 확인할 항목

| 주제 | 확인할 질문 |
| --- | --- |
| 시연 범위 | 홍수 외 재난 종류와 지역, 실제·모의 데이터의 구분은? |
| 위치 | GPS 실패·오래된 위치·권한 거부에서 알림과 영향 지역 표시는? |
| 데이터 | 공식 지시·위험지역·도로 통제·시설 접근성의 최신 자료를 확보할 수 있는가? |
| 추천 | 독립 이동·계단 제약·지원 필요 조건을 어떻게 확인하고 경로 후보를 검증하는가? |
| 음성 | 자동 시작·중단·끼어들기·권한 거부를 어떤 단말과 지연 목표로 지원하는가? |
| 연락 | 119 전화·문자·보호자 연락의 실제 연동 및 사용자 확인 단계는? |
| 3D | 경로 데이터와 지도 이용권한, 모바일 표시 성능, 해당 지역 제공 여부는? |
| 개인정보 | 위치·건강·연락처·음성 정보의 입력·보관·삭제 범위는? |
| 디자인 | 색상 후보 중 어떤 안을 선택하고 접근성 대비를 어떻게 검증하는가? |

원문에서 언급한 외부 통계·서비스 제공 현황·법률은 [원문 외부 출처 목록](references.md)을 통해 추적할 수 있으나, 현행성 확인은 이번 정리 범위에 포함되지 않았다.
