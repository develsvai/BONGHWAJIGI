## PPT 색상 검토

사용자는 기존 네이비·주황 포인트가 재난 대응 주제에 맞는지 물었다. 첫 답변은 네이비와 민트, 스카이블루, 앰버를 비교했다. 사용자는 A·B가 같은 푸른 계열이라 눈에 잘 띄지 않는다며 네이비 자체를 바꿀 수 있다고 했다. 이어 두 번째 답변은 아래 세 계열을 제안했고 **B안을 선호 의견**으로 제시했다. 사용자 최종 채택은 공유 대화에서 확인되지 않는다.

| 차례 | 안 | 핵심색 | 원문에서의 용도·인상 |
| --- | --- | --- | --- |
| 첫 제안 | 네이비 + 민트 | `#0B3056`, `#66DBC7`, `#FFFFFF` | 신뢰·안심 중심 |
| 첫 제안 | 네이비 + 스카이블루 | `#0B3056`, `#7DD3FC`, `#FFFFFF` | 기술 이미지 |
| 첫 제안 | 네이비 + 앰버 | `#0B3056`, `#F5B84B`, `#FFFFFF` | 재난 대응 강조 |
| 수정 제안 A | 차콜 + 세이프티 옐로 | `#202629`, `#FFD038`, `#F8F7F2`, `#D94A42` | 긴급성과 주목성 |
| 수정 제안 B | 딥 그린 + 밝은 옐로 | `#124F43`, `#F4E75E`, `#FFF9EA`, `#D94A42` | 보호·대피·안심 |
| 수정 제안 C | 아이보리 + 구조 레드 | `#F8F5ED`, `#CF3D3D`, `#25282B`, `#E6E4DE` | 구조·긴급구호 |

원문의 SVG 표지 비교 예시는 [M044 원문](archive/conversation-06.md#m044)에 보존했다. 색상은 PPT 제안이며 모바일 앱의 확정 디자인 시스템이 아니다. 사용자 PPT 이미지 원본은 공유 대화의 첨부 참조만 확인되어 이 폴더에 이미지로 복제하지 않았다.

## MVP 시연의 핵심 장면

사용자는 같은 재난에서 개인별 적합한 대피 방법이 달라지는 것을 MVP나 제출 영상에 보여주면 설득력이 높다고 했다. 답변의 제안은 **같은 홍수 대피 명령, 같은 위치와 재난 데이터를 유지하고 사용자 조건만 바꾸는 비교 시연**이다.

| 시연 단계 | 보여줄 변화 |
| --- | --- |
| 1. 평상시 | 지역 소식과 기본 프로필 |
| 2. 모의 홍수 명령 | 재난 전용 화면, 영향 지역 안의 내 위치, 공식 지시 예시 |
| 3. 사용자 A | 혼자 이동 가능 → 확인된 도보 경로의 3D 표시 |
| 4. 사용자 B | 이동이 어렵거나 계단 제한 → 다른 경로 또는 긴급 지원 |
| 5. 상태 변경 | 대화에서 새로운 제약을 말하면 상태와 결과 갱신 |

모의 데이터, 임의 지역, 가상 행동요령, 실제 연동되지 않은 신고는 화면과 영상에서 구별해야 한다는 제안이었다. 영상이 실제 안전한 대피 경로나 긴급 신고가 구현됐다는 증거가 되어서는 안 된다.

## 화면 디자인의 변천

첫 화면 초안은 7개 화면과 별도의 추천 결과 화면을 포함했다. 이후 사용자는 평상시 홈을 지역 소식 중심으로 바꾸고 재난 화면을 앞에 세웠다. 다음 수정에서 AI라는 단어를 버튼에서 빼고 음성 대화 화면 안에서 프로필을 갱신했다. 마지막 공유 대화에서는 원형 음성 모션과 발화 표시가 요구됐다.

더 최근에 추가된 [5개 화면 기획서](봉화지기_모바일_화면_기획서.md)는 긴급 화면의 중앙 파형과 단일 AI 발화, 사용자 발화 미표시, 조건부 3D 버튼 등을 명시한다. 시연 자료를 만들 때 이 최신 기획서와 첨부 예시 이미지를 함께 확인한다.
