# 확인한 제약과 처리

설계 문서에는 초기의 서버 사양·VPN 미확인 문장이 남아 있어 같은 날 후속 A2/A5 보고서를 함께 읽고 최신 확인 범위를 구분했다. 서버 자원은 기존 실측 기록이며 이번 Task의 현재 실측으로 표현하지 않았다.

최신 XGBoost GPU 문서에는 CUDA 12.9 이상 요구가 명시되어 있다. 기존 CUDA 드라이버 메모리 검사 성공을 XGBoost/torch 설치 호환성으로 간주하지 않고 후속 A3/C3의 작은 실제 학습·추론 검증 항목으로 남겼다.

FCM/APNs 토큰 계약과 인증 발급자·HTTPS 도메인은 확정되지 않았다. 구현할 어댑터와 모의 전송을 구분하고 실제 앱 토큰·제공자 설정·단말 수신 검증을 E1/E2에 남겼다.

실행 차단이나 사용자 승인 대기 항목은 없다. 서버 설치·모델 로딩·학습·부하 시험은 이번 문서화 Task의 실행 범위에 포함되지 않는다.
