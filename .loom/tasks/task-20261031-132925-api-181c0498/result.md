# 실행 결과

앱용 JWT 인증과 DB 계정·토큰 폐기, 자기 프로필/현재 상태/위치·설치·경보·현재 계획/과거 이력·갱신 cursor·수신 확인·전달 조회를 구현했다. 실제 실행 계약은 0.2.0-mvp의 21개 경로/28개 작업이며 최초 0.1.0-draft는 이력으로 보존하고 현재 계약과 차이를 명시했다. 원문과 개인 안내는 독립 조회하고 실제 예측은 unavailable/null이다.

서명 알고리즘·issuer/audience·필수 시각/소유권/시나리오·token_version을 검사하고 서비스 토큰과 사용자 토큰을 분리했다. 프로필 optimistic revision/멱등 키, 위치 관측 역순·재전송·삭제 후 복원 방지, 일시 상태 확인·만료, 토큰 회전·로그아웃, 위조/다른 사용자/만료 cursor, 개인별 알림 설정과 단말 보고를 구분했다.

## 검증

실제 PostgreSQL을 포함한 81개 전체 테스트 통과, Alembic check 일치, Ruff 정적/포맷, 실행 OpenAPI 생성과 기존 API 초안 검사·Loom strict 통과. 앱 경로는 21개/28작업이며 서버 음성·경로 도형·서버 신고 초안은 명시적으로 비활성이다. 기존 Starlette/httpx 경고 1개가 남는다. 앱 저장소·실제 예측 모델·GPU 학습은 변경하지 않았다.

## 후속

사용자 선택에 따른 사설망 일반 서버 배포와 실행 시연은 별도 승인된 Task task-20261031-132925-mvp-1d561841에서 이어서 수행한다. FCM/테스트 기기가 없어 실제 푸시/단말 인수는 수행하지 않는다. 개발용 JWT 발급 도구는 토큰을 권한 600 파일에만 저장한다. 문서는 mvp-app-api.md와 api/mvp-openapi.json이다.
