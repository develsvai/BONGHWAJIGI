# 결정

- 실행 전 초안과 실제 구현을 혼동하지 않도록 계약을 0.2.0-mvp로 구분하고 현재 OpenAPI·앱 사용법에 실제 응답 구조와 비활성 기능을 명시했다.
- 앱은 사용자 JWT만 사용하며 공유 서비스 토큰을 갖지 않는다. 공개 회원가입/운영 로그인 제공자 대신 사설망 시연 계정을 관리자가 발급한다.
- 프로필은 사전 정보, 5분 유효한 사용자 확인 관측은 현재 상태로 분리한다. 신고 지원은 모든 단계에서 단말이 서버를 기다리지 않고 연결하도록 유지한다.
- 실제 모델 연결을 요청 범위에서 제외했으므로 앱 영향 확률은 항상 unavailable/null이다. 서버 음성·3D·검증되지 않은 경로를 성공 응답으로 가장하지 않는다.
- 개인 데이터와 실험 중인 다른 학습 파일을 Git에 포함하지 않고 Task 소유 소스와 workflow만 커밋한다.
