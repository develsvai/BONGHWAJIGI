# 결정

사용자의 문서 재배치·한글 이름·중복 제거 직접 지시에 따라 실제 파일을 이동했다. 버전별 분류보다 문서의 역할을 우선하고, 현행 계약과 초기 계획은 구분했다. 링크만 나열한 완료 안내는 본문에 통합하며 고유 실험·출처·검증 수치를 보존한다.

기존 Loom 공개 CLI에는 Task 필수 문서 ID를 수정하는 명령이 없다. 작업 ID/의존관계를 교체하거나 metadata를 직접 고치지 않고 고정된4개 경로에 짧은 이동 안내만 남겼다. 사용자 자료의 실제 본문은 새 한글 경로에만 있다. 앞으로 찾는 시작점은 docs/문서안내.md이며 과거 증거의 경로는 이동표로 찾는다.

API 식별자·키·원본 데이터명은 한글화하지 않았다. 증거 JSON·이미지·PPTX/DOCX/XLSX/CSV와 원문 메시지는 재작성하지 않고 보존했다. 현재 탐색용 원문·발표 manifest2개의 파일 경로만 갱신했다. 과거 source-audit.json의 paths_read는 그 시점 실제로 읽은 경로라 보존했다.

앱 저장소, 운영 배포, 수집·학습 실행, 원격 push는 이 작업 범위가 아니다. 로컬 커밋과 Loom 완료 기록을 남긴다.
