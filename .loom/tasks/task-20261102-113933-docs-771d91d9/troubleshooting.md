# 확인한 제한과 처리

- 기존 문서에는 이미 삭제된 최종 발표 PPTX·아키텍처 ZIP·장문 외부 자원 명세 링크가 있었다. 없는 파일을 복원하거나 완료로 꾸미지 않고 보관된 PNG·PPTX·제작 도구·README 라이선스 표·조사 근거로 안내했다.
- 데이터 인계본은 외부 ZIP의 data/raw 경로를 manifest에 보존한다. 새 도구는 이를 자료/raw 경로에서 찾는다. 임시 합성 파일의 검사 성공과 실제 보관본15개 미복원을 분리했다.
- 이전 validate_app_api.py에는 기존 E501 줄 길이 경고17개가 있다. 기준 커밋과 현재 Ruff 코드/메시지별 개수를 비교해 동일함을 확인했고 새 경고3개는 수정했다. 이 작업에서 무관한 도구 전체 서식은 변경하지 않았다.
- 현재 API·수집 도구는 실제 로컬 경로를 수정했고, 과거 검증 JSON 속 해시/원시 경로는 의미 보존을 위해 그대로 두었다. 이동표가 원본 경로를 새 위치로 연결한다.
