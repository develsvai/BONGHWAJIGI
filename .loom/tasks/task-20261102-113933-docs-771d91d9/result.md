# docs 역할별 한글 문서 재배치 결과

기준일 2026-11-02. 기존 추적 파일 178개(자료 177개와 수집 폴더 .gitignore)를 전수 조사했다. Markdown 본문·역할·출처, JSON/CSV 규약과 증거, PPTX/DOCX/XLSX 내부 텍스트·목록, 이미지와 제작 도구를 확인하고 9개 역할 폴더로 재배치했다.

## 결과

- 서비스/설계, 설치/운영, 현재 API/앱 연동, 데이터 수집, AI 모델/연구, 시연/검증, 발표자료, 외부 자원/라이선스, 초기 설계/회의 이력으로 나눴다.
- 본문 문서와 증거·이미지·제작 도구 파일을 목적이 드러나는 한글 이름으로 변경했다. API 식별자·스키마·원자료 파일명·제품명은 의미를 바꾸지 않았다.
- 반복 안내 12개의 공통 완료 문구를 제거하고 고유 내용을 실제 본문 6곳에 통합했다. 별도 안내 문서 10개를 삭제했다. 내용이 다른 초기 설계·발표 시안과 원본 Word/Excel 형식은 이력으로 유지했다.
- docs/문서안내.md에 읽는 순서·역할별 폴더·전체 설명 문서 목록·최신/과거 경계·누락 산출물과 원본 보존 원칙을 모았다. docs/문서_이동표.csv는 178개 이전/현재 경로와 통합 절·이전 SHA를 전수 기록한다.
- 기존 대기 작업의 필수 문서 ID를 유지하려고 V2 아래 이동 안내 4개만 남겼다. 본문 복제는 없으며 Task ID·상태·의존관계를 바꾸지 않았다. 현재 파일 수는174개다.
- README·학습·시나리오 문서의 링크, 현재 OpenAPI 생성기·앱 소스 확인 도구의 서버 명세 경로, 이전 API 초안 검사 도구와 수집 도구의 파일 경로를 수정했다. 앱 저장소는 열람·수정하지 않았다.

## 검증

문서/이동표 전수 검증, 로컬 파일·앵커 959개, JSON36개 구문 검사, 바이너리/표본/실행 증거87개 바이트 동일, 원문56개 메시지 SHA/문자수와 진행 메시지15개 보존, 발표 manifest7개 SHA/크기 대조가 통과했다. 현재 OpenAPI 재생성은 바이트까지 동일했다. 이전0.1 초안25API/67스키마/48HTTP예제 검사가 통과했다. 제작 도구6개 JS 구문 검사와 변경 Python 구문/신규 lint 경고0 검사가 통과했다.

수집 도구는 임시 합성 보관본15개로 정상 해시·재생·손상 거부·누락 거부를 확인했다. 실제 별도 보관본15개는 저장소에 없어 real replay를 실행하지 않았고 원본 검증 성공으로 표시하지 않는다. 네트워크 수집·서버·GPU·학습·앱 실행은 하지 않았다.

Loom 문서 목록을 CLI로 갱신하고 대기5개 계약 참조와6jobs/63tasks strict 검증을 통과했다. 완료 이력 및 학습 출처/보고서·실행 증거 JSON의 옛 경로와 해시를 보존하고 이동표로 연결했다. 문서 재배치는 최신 상태 재측정이나 라이선스 재판정을 뜻하지 않는다.
