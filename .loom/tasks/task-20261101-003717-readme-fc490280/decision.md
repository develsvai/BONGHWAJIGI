# 결정

1. README가 서비스 소개와 실제 실행의 진입점이 되도록 구성한다. 멘토링의 제안, PPT의 기대 효과, 초기 설계와 현재 구현 완료 사실을 구분한다.
2. K8s는 수집 보류, 시나리오는 과거/합성, XGBoost는 서비스 미연결로 명시한다. 현재 Tailnet HTTPS·단말 로컬 알림·확인 후 상태 갱신은 최신 서버 기록을 따른다.
3. 사용자 아키텍처 원본을 수정하지 않는다. 이미 같은 SHA의 파일이 저장소에 있어 이를 사용하고, 이미지의 3위험과 현재3위급 명칭 차이는 캡션에 설명한다.
4. 운영 환경을 바꾸지 않고 CLI 도움말·임시 디렉터리의 설정 생성/Compose 검증·기본 API 상태와 안전한 Tailnet 읽기로 실행 예시를 확인한다. 실제 GPU 호출·학습 중단·운영 시나리오 주입은 수행하지 않는다.
5. README는 루트 파일이라는 사용자 요청이므로 Loom의 document_output_exceptions로 선언했다. 활성 Team Policy Snapshot은 없다. 앱 레포는 읽지 않았고 서버 인계 문서에 기록된 단말 결과만 참조했다.
6. 별도 학습 수정·보고서·기존 삭제·공용 이벤트를 이번 문서 커밋에 섞지 않는다. 현재 Task와 관련된 metadata만 구분하여 저장한다.
