# 결정

현재 상세 README를 유지하면서 누락된 화면·환경설정·라이선스·팀 역할을 보완한다. PDF의 문구를 구현 완료의 근거로 그대로 옮기지 않고 최신 저장소의 실제/연구·합성 범위를 유지한다.

화면은 PDF4쪽에서 JPEG를 원래 바이트로 추출하여 재그리기·재압축 없이 포함한다. 사용자 개인자료·토큰은 없음을 시각확인했다. PDF전체를 저장소에 복제하지 않는다. 팀 역할은 PDF9쪽을 근거로 하되 미확인 성능향상 수치는 추가하지 않는다.

외부 자원 조건은 공식 카드·약관과 저장된 메타데이터·확보판본 원문을 대조한다. 예전 삭제 문서를 복원하지 않고 현재 README에서 요약과 기존 조사 기록을 연결한다. 조사 시점의 의존성 목록을 최신 전체 SBOM으로 주장하지 않는다. Team Policy Snapshot은 없다.
