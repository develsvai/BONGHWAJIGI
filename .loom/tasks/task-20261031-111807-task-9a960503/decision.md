# 결정

- 사용자의 최종 목표는 국내 사용자 대응 판단에 연결할 1~6시간 영향·접근 위험이다. 미국 일별 NDWS 또는 국내 일별 관측 점수 개선은 그 목표 달성이 아니다.
- 기존 미국 모델을 기준선으로 보존한다. 기존 미국 test00은 이미 평가돼 재튜닝 후 최종 평가로 재사용하지 않는다.
- 국내 2025년을 잠금 구획으로 보존하고, 관측 시각·입력 발행/수신 시각·관측 불가 구분을 먼저 검증한다. 현재 확보한 MODIS 표준 아카이브·VIIRS 국가별 연간 요약은 사후 처리 자료이므로 as-of 가용성의 증거로 쓰지 않는다.
- 관측점이 없는 지역을 비화재로 바꾸지 않는다. 시간별 화재 위치와 관측 가능한 비화재 구역이 있어야 1·3·6시간의 확률을 검증할 수 있다.
- 사용자 프로필/기본 행동 지침은 정책 조합에 쓰고, 환경 영향 모델의 관측 정답 대신 넣지 않는다. 대응 레벨과 알림 회의 결정을 대신하지 않는다.
- 부득이한 실시간 NRT 입력도 수신 시각을 따로 남기고 과거 표준 제품과 동등성·지연을 검증한다. 키 없는 공개 경로 확보를 계속한다.
- 사용자에게 국내 1~6시간 FF API를 안내했고 이후 사용자가 실제 키를 제공했다. 키는 GPU training.env(600)에만 저장한다. typ01은 403, 사용자 신청 범위의 typ05 FF/KO는 실제 NetCDF 200을 확인했다. 제공된 CI/ELA 예시는 산불 FF/KO로 바꿔 사용한다.
- GOES 비교는 학습3/튜닝1/보정1 사건을 구분하고 모델·보정·임계값 고정 후 Smith River 미사용 사건을 1회 평가했다. 독립 사건에서 calibration logloss가 악화돼 보정 성공/국내 적용으로 보고하지 않는다. 이 최종 사건에 맞춰 추가 튜닝하지 않는다.
- 국내 FF 실제 원본은 재처리 제작 시각이 관측일보다 늦다. 관측+15분은 가정한 hindcast 지연일 뿐 실제 수신 시각이 아니다. 각 Parquet 행에도 assumed_delay_not_actual_release를 기록한다. 2025년 관측 정답은 계속 잠근다.
- 국내 프로토타입은 4개 학습 사건(안동2020/2021, 합천2022, 울진2022), 강릉2023 튜닝, 홍성2023 보정을 모델 적합 전에 정했다. 구름/누락/저신뢰/산업열을 음성으로 만들지 않는다.
- 국내 v1 구축 결과 강릉6h는 양성4/음성0으로 학습 전 검사에서 중지됐다. 모델 점수를 보기 전에 v2 탐색 설계로 홍성을 튜닝, 강릉을 보정 부족 진단으로 바꾼다. 정답 수를 본 뒤 수정한 사실을 숨기지 않으며 2025 최종 정답은 미열람 유지한다. Qwen은 중단 실패 후 두 모델 ready 복구 확인했다.

- 사용자 추가 지시 “최대한 예측 자료를 활용”에 따라 연구 범위 안에서 후보 검토 순위·과거 원본 재생·기간별 JSON/GeoJSON 인계를 구현한다. 기존 모의 확률 API나 H1~H3로 점수를 변환하지 않는다. 대응 단계는 별도 확정 정책 계약을 따른다.
- v3 최근60분 관측 입력 추가는 v2와 동일 행/정답/기존피처로 대조한다. v3 AP 소폭 개선보다 Brier 악화를 숨기지 않고 raw_model_score와 calibrated_probability=null을 구분한다.
- v4는 21개 비시험 지역 창으로 확장한 탐색 설계다. 유효 사건 수를 실제 기록하고 동시 발생 창을 독립 사건 수로 부풀리지 않는다. 2025 최종 정답은 계속 잠근다.
- 모델 평가용 미래 관측 필터가 재생 후보를 고르지 않게, 공통 input_snapshot을 정답 생성 앞에 분리했다. 읽기 cutoff 이전 원본만 연다. 후속 평가의 같은 시점10% 검토량도 개인 경보/누락 비용 기준으로 사용하지 않는다.
- 입력 출처는 모델/설정/자료보고서/원본/기상/정적 자료/코드 SHA와 가정 지연을 함께 남긴다. 신규 구축부터 관측소 좌표 등록부도 해시로 고정한다. 기존 v3 등록부는 학습 당시 해시가 없었다는 표시와 실측 피처 일치 검사를 남긴다.

- 사용자 모델 정확도 개선 요청에 따라 학습사건만으로 LOEO 후보선택을 고정하고 선택기록 후 기존홍성 검증을 평가했다. 기존에 본 validation임을 숨기지 않으며 2025최종평가를 튜닝에 쓰지 않는다.
- 일반화실험의 Brier는 줄었지만 AP는 악화돼 우수모델로 채택하지 않는다. 튜닝실패 결과도 모두 보존하고 자료 다양성·제품버전·관측정답/입력 개선에 우선순위를 둔다.
