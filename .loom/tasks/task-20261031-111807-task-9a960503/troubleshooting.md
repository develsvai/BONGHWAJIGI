# 복구 기록

- NOAA NCEI가 클라우드로 이관돼 기존 웹 주소는 HTML 탐색기로 바뀌었다. S3 실제 객체 목록으로 `isd-lite/data/<year>/` 경로를 확인했다. 최초 잘못된 경로의 404를 실제 무자료와 구분해 재수집했고, 실제 파일이 모두 없으면 성공 처리하지 않도록 보강했다.
- GitHub raw 경계 주소는 Git LFS 포인터를 돌려줬다. 발행 API의 실제 파일 링크로 변경했고 GeoJSON 구조를 검사한다.
- 일부 MODIS STAC 항목의 생성 시각·ID와 자산 내부 제작 시각이 달랐다. 내부 Dates/밴드/PRODUCTIONDATETIME 기준으로 처리하고 동일 위성·타일·날짜에는 실제 최신 제작본을 선택한다.
- 한국 ISD-Lite 강수는 누락이 많다. 누락을 0mm로 채우지 않으며 관측된 시간 강수량 합과 관측 수를 분리한다. 이 값은 일 총강수량이 아니다.
- 단일 연도 기상 수집이 과거 폐쇄 관측소 목록을 지우지 않도록 관측소 등록부를 수집 연도와 독립적으로 보존하고 연도별 manifest를 생성하도록 수정한다.
- GOES Oak 파일에서 M4 파일이 M6 파일보다 먼저 정렬돼 실제 관측 시간 역순이 발생했다. 실제 NetCDF 관측 시작 시각으로 정렬하며 같은 시점 재처리본은 최초 공개본을 선택한다. 스캔 모드 전환 회귀 시험을 추가했다. 투영 동일성은 속성 캐시로 확인해 반복 CRS 생성 비용을 없앴다.
- 처음 안내한 기상청 typ01 FF API는 발급 키에서 403이었다. 인증을 우회하지 않고 사용자가 제공한 typ05 신청 경로의 FF/KO를 검사해 200과 실제 NetCDF를 확인했다. 원본 없는 시각의 404는 누락으로 남긴다.
- KMA 원본 파일명은 ela020ge지만 실제 projection 변수는 LCC다. 참고 PDF의 구면 반경과 모서리 위경도가 충돌한다. WGS84 LCC는 공식 4개 모서리 위경도와 1e-6도 이내 일치해 이를 시험하고 연구용 변환에 채택했다. 운영 전 공식 조견표 대조는 별도 미완료다.
- KMA 프로필 수집 도중 429로 중단돼 수집 간격 3초 및 Retry-After/제한된 지수 대기를 반영했다. 이후 200 복구를 확인하고 원본 SHA 캐시부터 재개했다. 429는 결측/음성 정답이 아니다.
- 과거 기상 결합에서 가까운 관측소의 풍속 누락이 다른 관측소의 유효 과거 바람을 가리지 않도록, 1~3시간 전 유효 바람을 가진 주변 관측소를 조회한다. 강수 누락과 trace/무풍을 구분하는 시험 및 미래 관측 배제 시험을 추가했다.

- 공식 gk2a_ami_ko020lc_latlon.nc의 전체900×900 대조를 추가 완료했다. 최대 위도차6.91e-6도/경도차1.27e-5도이며 기존 WGS84 LCC 채택을 지지한다. 앞의 “조견표 미완료” 기록은 이 검사로 해소됐다.
- 홍성 양성의 현재 탐지점 거리 중앙값은16~17km다. 새 발화/가려진 화재 재관측/다른 화재를 구분하지 못하므로 물리적 화선 도달 정답으로 부르지 않는다. v3 가중 모델의 10% 검토량 recall도 최근60분 거리 기준을 이기지 못해 단순 기준을 함께 평가한다.
- 입력 스냅샷 추출 중 과거 프레임 부족 분기의 continue를 return으로 바꾼 오류가 새 단위 시험에서 검출됐다. 서버 배치 전에 수정했으며 실제 기존 Parquet2186행 피처 전체와 일치 검증했다.
- 성공한 transient systemd unit은 unload될 수 있어 loaded 상태만 요구하는 후속 감시기는 성공을 놓칠 수 있다. 학습 및 Qwen복구 후 디스크에 완료 영수증을 생성하고 후속 평가가 config/report/run SHA를 검증하도록 수정했다. 수집/학습은 중단하지 않고 기다리던 평가 감시기만 교체했다.
