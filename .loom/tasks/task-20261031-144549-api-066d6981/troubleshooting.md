# 확인된 한계와 처리

- 샌드박스 내부 SSH 연결은 차단돼 기존 사용자 서버접근 승인에 근거한 읽기 전용 escalated 명령으로 조회했다. 자동 승인 거절은 없었다.
- GPU 프로젝트 상대경로 .local/bin/uv는 존재하지 않았다. 필요없는 버전 재조회는 확대하지 않고 기존실측/배포 고정버전 0.11.10 근거를 사용했다.
- source-audit 초기 KMA/FIRMS 상태는 과거 조사 기록이므로 후속 실제수집 보고서로 정정해 해석했다.
- 일부 upstream 페이지와 패키지 metadata의 라이선스가 비어 있거나 판본조건이 불명확하다. 근거없는 SPDX를 부여하지 않고 미확정 항목으로 남겼다.
- 전체 OS 패키지와 앱에 대한 완전한 SBOM이라고 주장하지 않는다.
