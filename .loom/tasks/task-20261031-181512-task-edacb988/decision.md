# 결정

기존 앱 배포 Job의 새 후속 Task로 지도 APK의 메인 pin과 출처 문서를 관리한다. 최종 앱 QA와 원격 SHA를 받기 전에 고정 완료로 표시하지 않는다. 공식 지도 SDK와 MIT React Native wrapper의 권리 조건을 구분하며 일반 지도 배경을 안전한 대피 경로로 표현하지 않는다.

external-resources-and-licenses.md에는 다른 학습 작업의 추가가 진행 중이다. 작업 파일을 덮어쓰지 않고 네이버 지도 관련 항목만 변경하며, Git index에는 HEAD 내용에 이 Task의 변경만 반영한 blob을 stage한다. 기존 training/presentation 변경은 그대로 보존한다. 지도 Key ID·Secret은 조회·기록하지 않는다.
