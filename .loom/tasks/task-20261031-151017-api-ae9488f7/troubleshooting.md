# 확인 및 복구

작업 중 같은 문서의 기존 조사 결과가 다른 실행에서 커밋된 것을 발견했다. 기존 커밋 문서를 기준으로 병합하여 안전한TV 제4유형·실제 설치환경 증거를 보존했다. 완료 Task는 다시 열지 않았다.

Embedding 고정 revision에는 별도 LICENSE 파일이 없고 공식 카드가 Apache2를 선언한다. cuda-toolkit 두 메타패키지도 동봉 LICENSE가 없어 자체 조건 미확인으로 남겼다. 실패한 추측 URL은 성공 근거로 표시하지 않았다.

필수 결과와 검증은 완료했다. 미확인 제품별 권리는 외부 공개·재배포 범위 확정 시 원 공급자 조건을 확인해야 한다.
