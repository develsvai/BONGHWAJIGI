# 결정

- 사용자 답변에 따라 Job 2를 앱 연동 API 계약과 인계 Job으로 특정했다. 번호 추측으로 다른 Job을 변경하지 않았다.
- 기존 E1/E2의 선행 작업이 미완료이므로 새 선행 문서 Task E0로 실행했다. 사용자 직접 지시로 초안을 작성하며 선행 작업이나 실제 서버 검증을 허위 완료 처리하지 않는다.
- V2의 공식 긴급 우선, AI 임의 행동 결정 금지, 환경 확률과 개인 대응 분리를 유지하고 최신 5개 화면만 API 매핑의 요구로 사용했다.
- 음성 턴과 3D는 조건부 계약이고 기본 capability는 꺼진다. 텍스트 턴을 실시간 오디오 구현으로 표현하지 않는다. 모델 상태 제안과 사용자 확인 저장의 스키마를 분리했다.
- 119는 문자 초안과 단말 연락 UI로 구분한다. API는 실제 전송/통화/접수를 수행하지 않으며 not_sent를 반환한다.
- 인증 발급자·API 실제 주소·개인정보 수집/보관·정책 임계값은 미정으로 공개했다. 건강·연락처·주소를 임의로 추가하지 않는다.
- 문서·스키마·예제의 유지보수를 위해 독립적인 검증 스크립트와 고정 검증 도구 버전을 제공했다. 실제 연락/운영 서버 호출은 검사에 포함하지 않는다.
