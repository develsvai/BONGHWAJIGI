# 문제 해결

- 검증 도구는 기본 환경에 없어 공식 PyPI의 고정 버전을 임시 가상환경에 설치했다. 프로젝트 서비스나 서버 런타임은 설치하지 않았다.
- 첫 예제 검사에서 문자 초안 예외 fixture가 201 대신 200을 사용한 불일치를 발견해 수정했다.
- 검증 보고서가 첫 생성 전에는 없는 파일이라 링크 검사가 실패했다. 현재 생성 요청 대상 보고서만 예외로 인정하고 다른 링크는 실제 존재 여부를 검사하게 했다.
- 모델 제안에 user_confirmed 필드가 포함될 수 있는 초기 설계를 수정했다. 확인 전 proposal과 확인 후 ContextWrite를 별도 스키마로 만들고, 계단 관련 발화만으로 혼자 있음을 추정하는 예제도 제거했다.
- 오늘의 안전 행동요령은 여러 재난을 포함할 수 있으므로 단일 재난의 기본 수칙과 분리한 DailyGuidance로 정의했다.
- 문서 수정 패치의 기존 문구 불일치는 파일을 재확인해 범위를 좁혀 적용했다. 사용자 원본 HeoNey 문서는 수정하지 않았다.

## 남은 위험과 다음 행동

실제 인증·데이터·정책·API 주소·운영 시간값과 선택 기능의 범위는 미확정이다. 앱팀은 모의 연동을 진행하고 E1/E2에서 계약 승인 및 실제 서버 호환을 확인한다. 정적 예제 성공으로 실제 재난 대응 성능이나 단말 수신을 보장하지 않는다.
