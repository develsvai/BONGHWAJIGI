# 문제와 처리

- 기본 sandbox의 Docker/로컬 DB/SSH 접근 제한은 기존 사용자 요청 범위로 권한 검토를 거쳐 실행했다. 자동 승인 거절은 없었다.
- SSH는 제공받은 기존 계정의 숨겨진 비밀번호 프롬프트로 연결했다. 비밀번호나 서비스 토큰을 명령행·산출물·저장소에 기록하지 않았다.
- 정책 계약을 분석 계약에서 역참조하면 import 순서에 따라 순환 참조가 발생할 수 있어 공통 사각 구역·정책 연결 계약을 contracts/spatial.py로 분리했다.
- 마이그레이션 자동 생성 결과의 의존 관계와 제약을 검토하고 포맷했다. 실제 upgrade와 Alembic check에서 코드와 DB 차이가 없음을 확인했다.
- 경보 ID 접두사의 SQL LIKE 와일드카드를 escape하고 다른 시나리오·사건 조회 검사를 추가했다. GPS 오차·경도 경계는 확정 판단을 보류한다.
- 새 입력 반영 전 조회에 옛 행동이 남을 수 있어 pending_update/실패/만료 시 행동·확률을 가리는 처리를 추가했다. 최신 평가가 끝나면 정상 조회한다.
- 현재 Starlette TestClient의 httpx deprecation 경고 1개가 남지만 57개 테스트는 모두 통과했다. 의존성 변경은 이번 범위가 아니다.
