# 결정

- 사용자가 직접 구현을 요청한 범위를 같은 개인별 대응 정책 Job의 새 Task로 실행했다. 미결정 정책표를 포함한 기존 Task는 완료로 변경하지 않는다.
- 상태 갱신은 새 입력 이벤트와 주기 만료 점검을 함께 사용한다. 입력과 대상 재평가 요청을 PostgreSQL 트랜잭션에 묶고 버전·내용 해시·요청/적용 번호를 기록한다.
- 개인별 규칙은 DB 참고 문구의 조건형 적용으로 한정한다. Qwen은 출처가 연결된 사건 설명을 제공하며 대응 단계·행동·확률을 생성하는 권한을 주지 않는다.
- 레벨과 알림이 회의 중이므로 unknown/configuration_pending으로 유지한다. simulation_only는 운영 승인과 다르며 기본 seed도 합성 검증용이다. approved 입력은 지원하지 않는다.
- Qwen 통합과 정책 갱신은 독립 프로세스로 실행해 생성 지연/장애가 프로필·위치·기본 지침 적용을 막지 않게 한다.
- 새 관측이 오면 이전 revision의 늦은 생성 결과는 superseded로 남기고 최신 계획을 덮어쓰지 않는다. 완료와 재평가 요청은 같은 트랜잭션이다.
- 위치 정확도·시각·유효 기간과 사각 구역 관련성을 확인하고 경계/자료 불명확은 보류한다. 구역 밖이나 자료 만료를 안전으로 해석하지 않는다.
- 모의 예측/예측 불가 입력은 수용하되 현재 검증되지 않은 확률을 레벨 전환에 사용하지 않는다. 학습 작업을 호출하거나 모델 가중치를 변경하지 않는다.
- 실제 앱 인증이나 상시 배포는 확장하지 않고 simulation 내부 서비스 API와 로컬 실행 도구로 구현·검증한다. 개인 프로필은 외부 검색어나 자동 Qwen 요약 입력에 추가하지 않는다.
