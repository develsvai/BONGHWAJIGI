# 결정

사용자 후속 요청을 같은 실행·배포 Job의 새 Task로 수행한다. 서버 음성은 추가하지 않고 텍스트와 사용자 확인 상태 제안에 한정한다. Qwen의 역할을 정책 행동 선택·상태 추출로 제한하고 안내 문장은 검토된 정책 텍스트로 구성한다. proposal_turn_id를 기존 context 확인에 추가해 만료·다른 세션·정책/input 변경·변조를 거부한다. 사용자 확인 전 정책 입력을 쓰지 않는다.

시연 경로는 서버 JSON fixture이며 mobile-demo/mobile-fire 합성 사건과 fresh 근접 시연 위치에서만 반환한다. 실제 안전 경로·길찾기 API·GPS검증으로 표현하지 않는다. 다른 채팅의 학습/라이선스/발표 변경과 앱 서브모듈은 이 Task에서 stage하지 않는다.
