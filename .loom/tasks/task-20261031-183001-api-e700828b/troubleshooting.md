# 확인 사항

로컬 PostgreSQL 검증은 샌드박스의 loopback 접속 제한으로 최초 연결이 거부됐다. 승인된 로컬 테스트 DB 접근 권한으로 재실행하여 migration과120개 테스트를 통과했다.

Qwen 출력의 행동ID·근거문구·필드 타입을 검증하며 잘못된 출력/모델 실패는 기존 정책 안내 fallback이다. 초기화된 모델의 존재만으로 API 기능 검증을 완료 처리하지 않고 실제 서버배포 후 다시 확인한다.

읽기 리뷰에서 생성 후 입력이 바뀐 turn의 상태가 rollback되어 잠시 busy로 남는 문제를 발견했다. 최종 검증 실패는 superseded로 확정한 뒤 오류를 반환하도록 보완하고 새 turn 즉시 성공을 검증했다. 실제 AppSession 두 개의 교차 조회/재전송/제안확정 404와 생성 중 세션취소 401 회귀 검사도 추가했다. 전체120개 테스트가 통과했다.
