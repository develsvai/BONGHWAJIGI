# 결정

사용자의 이번 직접 지시가 현재 레포의 모든 변경을 커밋·푸시하도록 승인하므로 다른 채팅에서 작성한 학습 및 서버 연동 파일도 현재 저장된 상태로 포함한다. 별도 앱 레포는 제외한다. 무시된 비공개 설정·다운로드 원본·모델 캐시는 추가하지 않는다.

다른 채팅의 실행·Task 상태를 종료하거나 코드를 재작성하지 않는다. 처음 관측한 작성 중 코드의 서식 실패와 이후 저장으로 해결된 최종 통과를 구분해 기록한다. 기능시험 통과와 실제 운영/DB 통합 검증 범위를 구분한다.

Git 전체 스테이징 후 정확한 index 내용의 비밀정보·크기·Python 구문을 검사하고 일반 push한다. 사용자 변경 폐기, 강제 push, 이력 재작성, 승인 없는 배포는 수행하지 않는다. Team Policy Snapshot은 없다.
