# 점검과 복구

합성 응답 캡처가 fixture의 기존 위치와 같은 시각의 다른 fix를 보냈을 때409로 거부됐다. 역순/중복 보호가 맞는 것을 확인하고 새로 생성한 격리 fixture의 기본 위치만 제거해 최초 앱 입력을 검증했다. 실제 사용자 데이터는 삭제하지 않았다.

앱이 현재 상태/정책 입력revision을 혼동할 수 있어 명시적 user_context와 input_revision을 제공했다. 기존 계단 override가 반영되지 않던 문제를 찾고 H2의 독립 사용자가 현재 계단 어려움을 확인하면 경고에서 대피로 갱신되는 검증을 추가했다.

현재 서버 배포는 별도 단계다. 등록은 기본off이며 실제 예측/지도·경로·FCM 실발신/서버STT·TTS는 제공 상태로 변경하지 않았다.
