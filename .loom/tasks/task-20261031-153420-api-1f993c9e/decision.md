# 결정

사용자의 앱 구현·검증·APK 요청에 필요한 서버 공백을 보완했다. 외부 계정·결제 없이 사설망 시연에 한해 설치 계정을 등록하고 기존 계정ID를 임의로 인계하지 않는다. refresh는 회전과 재사용 폐기를 지원하고 앱에 공유 서버 키를 넣지 않는다. 개인정보 추가 필드는 정규화한 정책 입력과 분리해 의료 메모를 모델/정책에 자동 전달하지 않는다. 앱 문서revision과 정책 input_revision도 분리했다. 서버 정책 텍스트를 단말 TTS로 읽고 voice-turns/서버오디오는 비활성 상태를 유지한다.

다른 채팅의 전체 저장소 체크포인트562b2bc/a13644f에 작업 중인 서버 세션 변경 일부가 포함된 사실을 확인했다. 이를 되돌리지 않고 후속 출력 모델과 최종 검증을 이 Task의 완료 커밋으로 남긴다. 학습 코드는 스테이징하지 않는다.
