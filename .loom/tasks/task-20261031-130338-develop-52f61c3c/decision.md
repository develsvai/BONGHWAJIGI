# 결정

- 사용자가 현재 변경 전체의 커밋과 원격 동기화를 명시적으로 요청했으므로 진행 중인 다른 학습 실험의 현재 변경도 체크포인트에 포함한다. 해당 학습 Task의 상태나 결과는 대신 완료 처리하지 않는다.
- develop에서 작업하고 기존 로컬 16개 커밋과 원격 3개 커밋을 merge로 보존한다. 강제 push, rebase에 의한 기존 이력 재작성, reset, 사용자 변경 폐기는 하지 않는다.
- 작은 실험 모델 파일과 평가 보고서는 사용자의 전체 변경 보존 지시에 따라 포함한다. 원시 다운로드 자료·인증정보·로컬 가상환경은 기존 Git 제외 규칙을 따른다.
- 실제 GPU 학습과 모델 서비스에는 접속하거나 상태를 변경하지 않는다. 앱 저장소도 범위에서 제외한다.
- 제안한 대응 레벨 설계의 코드 적용이나 다른 기능 구현을 이번 동기화 작업에 추가하지 않는다.
