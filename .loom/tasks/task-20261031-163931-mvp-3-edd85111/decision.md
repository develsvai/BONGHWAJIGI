# 결정

사용자의 2~3장 요청에서 3장을 선택했다. 전체 흐름·모델 역할·긴급 및 갱신 경로를 나눠 교차 연결선을 없애고 편집 가능한 도형과 직접 만든 아이콘을 사용했다. 실행 완료와 연구·미연결 상태를 그림에 함께 표시했다.

Qwen 결과를 개인 단계 결정이나 XGBoost의 검증된 입력으로 표현하지 않는다. 임베딩 벡터 생성과 일반 서버 DB 검색을 구분한다. 신규 ELMFIRE 등 연구 도구는 서비스 배치에 포함하지 않고 비교 문서에서 별도 연구 상태로 설명한다.

관련 자료와 정확한 비교 근거는 발표자 노트와 Markdown에 두고 슬라이드에는 필요한 흐름만 제시한다. 진행 중인 다른 채팅의 학습·앱 API·Loom 변경은 보존한다.
