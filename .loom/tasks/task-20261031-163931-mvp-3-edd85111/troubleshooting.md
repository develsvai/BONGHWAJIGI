# 해결한 문제와 남은 조건

프레젠테이션 작업 표식의 복합 출력 형식 인수가 지원되지 않아 pptx 단일 형식으로 수정해 정상 실행했다. 글자 폭 점검에 fontTools가 설치되지 않아 기존 Pillow의 시스템 글꼴 측정으로 대체했고 일반·굵은 글꼴을 모두 확인했다. 미해결 산출물 오류는 없다.

PowerPoint/SVG 지정 글꼴은 Apple SD Gothic Neo이며 글꼴 파일을 배포하지 않는다. 글꼴 설치 여부와 무관하게 사용하려면 PNG를 넣으면 된다. 서버·앱 연결의 남은 작업은 별도 진행 중 Task에 유지하며 이 문서 완료로 대체하지 않는다.
