# 미해결 항목과 복구

기본 실행 환경에서 원격 네트워크 접근이 거절됐다. 읽기 전용 네트워크 권한으로 재시도하여 K8s와 두 SSH 포트의 접근을 확인했다.

SSH 비밀번호를 터미널에 전달하는 단계는 자동 승인 검토에서 거절됐다. 검토기가 사용자 메시지에서 비밀번호와 전송 승인을 확인하지 못했다는 사유였다. 첨부 이미지 계정 및 비밀번호의 두 서버 SSH 사용 승인을 별도 질문했으며 현재 대기 중이다. 다른 도구나 간접 실행으로 우회하지 않았다. 인증정보는 파일, 보고서, 작업 로그에 남기지 않았다.

일반 서버는 로컬에 호스트 키가 등록되지 않아 엄격한 키 검사 단계에서 종료됐다. 승인 후 최초 접속의 키 확인과 등록 절차를 수행하고 로그인 후 예상 서버와 일치하는지 확인해야 한다.

클러스터 마스터의 DNSConfigForming은 nameserver 제한 초과에 따른 일부 DNS 생략 경고다. 현재 Ready 상태와 별도로 실제 DNS 해석 영향은 A2에서 확인한다. 높은 누적 재시작은 과거 종료 시각으로 현재 장애와 구분했다.

기존 문서 5개의 V1 이동과 HeoNey의 미완료 문서화 상태는 이번 작업의 수정 범위가 아니므로 그대로 유지했다. 이번 결과는 전체 저장소가 깨끗하다는 주장이 아니다.
