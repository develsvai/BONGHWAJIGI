# 결정

- 사용자의 질문은 직접 시작하는 방법 안내로 해석했다. 이전 학습 담당 지시에 따라 실행기를 구체적으로 준비하되 실제 Qwen 중단·전체 GPU 학습을 자동 시작하지 않았다.
- 서비스 중단은 사용자가 실행할 wrapper에 명시하고 기존 활성 상태를 기억해 정상/오류/INT/TERM 후 복구한다. 기존 GPU 잠금을 공유한다. 강제 SIGKILL·전원 차단 후에는 수동 확인이 필요하다.
- SSH 종료와 무관한 systemd 사용자 unit을 시작 명령으로 제공했다. 실행 전 자료 검증을 먼저 하고, 출력은 새 디렉터리에만 만든다.
- 피처 목록으로 입력을 제한하고 test는 기본 평가하지 않는다. validation 조기 종료와 최적 회차 저장을 적용하며 운영 사용/보정 여부를 false로 남긴다.
- 대용량 Tailnet 전송이 느려 코드를 먼저 전달하고 서버에서 승인된 원본을 직접 다운로드·재생성했다. 공개 자료만 사용했고 별도 환경으로 root 서빙 의존성을 보호했다.
- 플랫폼 간 코사인 파생 값의 미세한 바이트 차이는 별도 서버 데이터 보고서로 기록했다. 동일 seed가 다른 플랫폼의 동일 모델을 보장한다고 주장하지 않는다.
