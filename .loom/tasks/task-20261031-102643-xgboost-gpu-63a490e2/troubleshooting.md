# 문제와 해결

- `loom task run --agent foreground`는 현재 CLI의 구식 외부 실행 호환 경로여서 거부됐다. 파일 변경 전에 인자 없는 `loom task run <id>`로 foreground 세션을 정상 생성했다.
- BatchMode SSH는 공개키 인증이 없어 거부됐다. 사용자가 기존에 제공한 자격으로 대화형 로그인했고 비밀번호는 파일·보고서에 보관하지 않았다.
- 약 612MB Tailnet 전송은 1MB/s 수준으로 느렸다. 작은 코드 archive만 전달해 서버에서 Kaggle v2를 직접 내려받고 원본 해시·Parquet·전체 배치를 확인했다. 중단된 부분 archive와 자체 생성 임시 archive는 양쪽에서 정리했다.
- 문서 패치에서 존재하지 않는 README 문맥이 두 차례 거부돼 적용되지 않았다. 실제 문맥을 사용한 개별 패치로 반영했다.
- validation Parquet SHA256이 맥과 달라 모든 입력·정답 열을 비교했다. wind_direction_cos만 바이트 차이가 있고 소수 6자리 반올림 열 해시는 일치했다. 원본·나머지 열·정답은 일치하며 서버 자체의 보고서/해시 검증을 통과했다. 전체 byte-identical이라고 기록하지 않았다.

# 제한

전체 GPU 학습은 사용자가 시작할 단계다. 테스트한 복구는 정상/오류 경로와 잠금 동작이며 실제 서빙 중단을 동반한 wrapper 전체 실행은 하지 않았다. CPU 일부 표본 성능은 채택 근거가 아니며 test·보정·국내 외부 검증은 남아 있다.
