
## CLI생성입력 공백

초기계약 description의 줄끝공백이 새 prompt/context에 그대로 재생돼 git diff --check가 해당파일을 지적했다. 생성입력은 원문증거로 유지하고 정확한파일·SHA를 기록한뒤 제외한 일반문서/산출물 공백검사를 통과했다. 메타데이터를 직접고치지 않았다.

## 취소 항목의 고아 실행 기록

사용자가이미취소한외부문서통합의legacy상태는CANCELLED였지만shadow실행은RUNNING으로남아삭제CLI가거부했다. CLI review로실행기록만종료한뒤삭제했다. 취소된통합을실제로수행하거나완료했다고꾸미지않았다. 삭제/임시재배정후원소속·의존성을검사해Loom strict를통과했다.
