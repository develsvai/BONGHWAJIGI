# 문제 해결 및 남은 조건

1. 일반 서버 이미지의 비밀번호 판독 오류: 사용자가 정확한 텍스트를 제공한 후 기존 VPN과 Tailnet 모두 SSH 로그인에 성공했다. 비밀번호는 기록하지 않는다.
2. 기존 cody-stat Tailscale 진단의 기본 소켓 연결 실패: 실제 컨테이너 설정의 /tmp/tailscaled.sock을 사용해 조회를 복구했다. 기존 서비스 설정은 변경하지 않았다.
3. Tailscale 진단 ping은 되지만 TCP 연결 실패: 두 서버의 유효 PacketFilter가 빈 배열이었다. 호스트 방화벽과 SSH 리스닝을 확인했고 사용자 승인 후 최소 TCP 22 grant를 추가하자 마스터·서버 상호·노트북 접속이 통과했다.
4. 브라우저 출발지 숫자 입력 일부 누락: 저장 전에 읽은 값으로 발견했고 붙여넣기 방식으로 정확한 IP를 입력했다. 최종 JSON 미리보기와 배포된 필터를 확인했다.
5. 일반 워커·파드의 연결 실패는 남아 있다. 전용 egress와 서비스 접근 정책을 A3에서 구성하고 실제 API를 시험해야 한다. 다른 서비스의 userspace 사이드카를 공용 출구로 사용하지 않는다.
6. GPU의 기존 Mellanox 인터페이스 서비스 및 fabricmanager 실패 상태는 이번 변경과 별개다. 기존 A2 분석을 참조한다.

키 만료 전 운영 정책 확정, API 포트별 최소 허용, 파드 재시작 후 연결 복구 시험이 후속 조치다.
