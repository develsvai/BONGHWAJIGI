# 결정

- 사용자의 실제 완료 로그 검증 지시에 따라 특정 모델 SHA256을 고정하고 읽기 전용 상태 확인·CPU 재추론으로 검증했다. 이미 복구된 Qwen 서비스를 다시 내리지 않았다.
- 학습 보고서의 test_evaluated=false는 당시 사실로 보존하고 이번 첫 test 평가 결과는 별도 audit.json에 남겼다. 해당 모델에 대한 추가 학습·튜닝·임계값 선택을 하지 않았다.
- 기준선 AP는 동일한 이전 관측 유효 행에서 비교했다. AP/ROC-AUC를 정확도나 개인 피해 확률로 부르지 않는다.
- 0.5는 진단 임계값으로만 사용했다. 낮은 재현율이 확인됐으나 임의로 경보/대응 레벨 임계값을 정하지 않았다.
- 이번 test 평가 이후 같은 test로 튜닝하면 최종 독립 평가로 재사용할 수 없음을 명시했다. 미국 일별 위성 관측 모델의 연구 범위를 유지했다.
- 실행 시간은 추정 대신 실제 report 24.869초와 journal 약 31초로 정정했다. 모델과 작은 실제 근거 사본을 Git에 보존하되 운영 배포는 하지 않았다.
