# 확인한 사항

- 오류나 모델 파일 손상은 발견되지 않았다. 원본 모델 해시·학습 당시 데이터 보고서 해시·전체 Parquet·64회 이력·34개 트리와 validation 재추론이 일치했다.
- 300회 이전 64회 종료는 최고 회차 index 33 이후 30회 개선 없음에 따른 정상 조기 종료였다.
- 학습 로그 aucpr과 최종 sklearn AP는 계산 정의가 달라 미세하게 다르다. 같은 모델의 validation AP 재계산은 기존 보고서와 일치했다.
- GPU 사용률 0% 화면은 학습 완료 후다. 약 9GB 메모리는 복구된 Qwen 프로세스였고 실제 두 모델 ready를 확인했다.
- 0.5 임계값에서 test 재현율 0.0233%라는 한계를 확인했다. 학습 성공을 경보 성능 채택으로 해석하지 않는다.
- 실제 파이프라인은 24.869초여서 앞선 5~10분 추정은 과대했다. 측정값으로 정정했다.
