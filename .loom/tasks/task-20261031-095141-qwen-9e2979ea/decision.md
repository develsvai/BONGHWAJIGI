# 구현 결정

- 사용자의 현재 지시를 직접 실행했다. MVP는 실제 K8s 수집 없이 시나리오를 수신하며 인터넷 검색도 포함한다는 사용자 선택을 반영했다. 생성·통합 모델 호출 직전에서 멈춘다.
- 이벤트와 outbox는 PostgreSQL에 함께 저장하고 Redis로 나중에 전달한다. 중복을 허용하는 전달과 DB job 잠금·완료 상태 검사로 멱등 처리를 구성했다.
- 인터넷 검색은 키 없는 Google News RSS 어댑터로 시작하고 제목·짧은 설명·원문 링크·매체·시각만 보관한다. 확인되지 않은 외부 자료는 verified=false, 정책 승인 false로 남긴다.
- 일반 API 토큰과 GPU 임베딩 토큰은 분리했다. 기존 GPU 서비스와 공개 포트를 변경하지 않고 SSH 터널로 실제 임베딩을 검증했다. 검색어만 외부에 전달하고 전체 입력·사용자 프로필을 자동으로 보내지 않는다.
- 검색은 같은 scenario와 산불 유형, 고정 임베딩 revision, 평가 시점의 유효 자료로 제한한다. cosine 유사도는 영향 확률이 아니다. Qwen tokenizer 예산 검사는 다음 단계 책임으로 명시했다.
- 동시 진행 중인 다른 XGBoost Task와 training/ 변경은 보존한다. 이번 Task 소유 코드·기록만 커밋한다. Verified Team Policy Snapshot은 없다.
