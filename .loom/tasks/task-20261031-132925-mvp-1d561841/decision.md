# 결정

- 사용자의 기존 지시에 따라 실제 예측 연결을 제외한 서버 MVP를 상시 배포한다. 경고·대피·위급 이름을 사용하며 앱 저장소와 진행 중인 학습 작업은 제외한다.
- 실제 Firebase와 도메인은 미준비라는 사용자 답변에 따라 simulation 발신과 사설망 SSH 접속으로 고정한다.
- 일반 서버의 GPU 토큰 보유와 API 포트 전용 키 등록은 자동 승인 거절 후 사용자가 명시적으로 허용했다. 토큰은 권한 600 설정에만, 개인키는 일반 서버에만 두고 GPU authorized_keys를 8001 포트로 제한한다.
- GPU 연결이 없어도 긴급 큐·정책·조회는 독립 실행한다. 모델은 실제 예측에 연결하지 않는다.
- Docker Compose/Linux host network를 사용하고 DB/Redis는 loopback과 영속 볼륨으로 제한한다. 원래 K8s 구성을 보존한다.
