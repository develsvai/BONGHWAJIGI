# 문제와 복구

- 자동 승인 검토가 기존 GPU 토큰의 일반 서버 복사에 대한 명시적 승인 부족으로 mvp_provision 실행을 거절했다. 우회하지 않고 사용자에게 이유와 구체적 전송 범위를 설명했다. 사용자가 “허용 — 비공개 설정과 제한된 연결 키로 구성”을 선택한 뒤 동일한 도구를 재실행했고 비공개 설정 생성에 성공했다.
- 일반 서버에는 실행 환경이 없어 Docker와 Compose 패키지를 설치했다. 기존 GPU 서비스/학습을 재시작하지 않았다.

- 첫 서버 시연은 정상 HTTP 200인 경보 수신 확인을 도구가 202로 예상해 멈췄다. 실행 OpenAPI/구현에 맞춰 도구 기대값만 수정하고 정상/GPU 미연결 전체 시연을 다시 통과했다.
- SSH Match 제한 문서는 GPU에 설치된 OpenSSH 설명서를 확인했다. 서버에 rg가 없어 대체 검색을 사용했으며 검사 후 reload는 기존 SSH 연결을 끊지 않았다.
- 남은 차단 사항 없음. 실제 푸시/도메인/단말은 사용자 답변에 따른 후속 외부 연결 조건이다.
