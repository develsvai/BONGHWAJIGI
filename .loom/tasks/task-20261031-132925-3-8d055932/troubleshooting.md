# 검증 중 조정

- 기존 긴급 워커 시험은 미구현 예외를 기대했다. 실제 구현에 맞춰 독립 처리기로 위임되는지와 호출 전후 GPU/분석 워커 미로딩을 검사하도록 갱신했다. 최종 73개 시험이 통과했다.
- 실제 푸시 설정은 사용자 답변으로 없는 상태를 확인했다. FCM은 공식 HTTP v1 규약을 MockTransport로 검증하고 실제 단말 전송으로 주장하지 않는다.
- 진행 중인 학습 작업이 공용 events/docs-index와 training 파일을 갱신 중이다. 해당 변경을 덮어쓰거나 학습 완료로 변경하지 않고 Task 소유 변경만 커밋한다.
