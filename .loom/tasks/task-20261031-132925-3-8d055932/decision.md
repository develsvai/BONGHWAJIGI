# 결정

- 사용자 승인 원문에 따라 3단계를 확정하고 후속 지정한 경고·대피·위급 명칭을 적용했다. API prepare/act/request_assistance를 유지하며 확인 중/도착 후는 단계 밖으로 둔다.
- MVP 전용 고정 정책과 국내 기본 지침만 승인 상태로 등록한다. 해외 고립 행동과 거리/확률 임계값을 임의 적용하지 않는다. Qwen과 실제 예측 모델은 정책 선택 권한이 없다.
- scope → projection → change sequence 순서로 DB 잠금을 통일해 입력/평가 간 교착과 cursor 누락을 방지한다. 네트워크 전송 중에는 DB 트랜잭션을 잡지 않는다.
- 공식 원문 처리와 알림은 GPU와 별도 큐다. 푸시는 민감 본문 대신 리소스 식별자와 revision만 전달하고 API에서 최신 내용을 조회한다.
- Firebase 설정 미확보와 사설망 개발 배포에 대한 사용자 답변을 후속 Task에 적용한다. 다른 학습 작업의 파일과 C Job 진행 상태는 보존한다.
