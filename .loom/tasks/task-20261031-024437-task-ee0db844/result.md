# 결과

사용자가 올린 `nomal_home.png`와 `disaster.png`를 `docs/HeoNey/봉화지기_모바일_화면_기획서.md`의 1번 평상시 홈과 2번 긴급 재난 대응 화면에 삽입했다. 두 화면의 텍스트 와이어프레임은 제거했고, 긴급 화면의 상단과 스크롤 후 모습은 한 장의 이미지에서 좌우 패널로 설명했다.

3D 대피로, 프로필 설정, 재난별 기본 수칙은 해당 이미지가 없어 기존의 텍스트 예시를 보존했다. 이미지 속 오래된 문구가 최신 요구를 덮지 않도록 홈의 ‘발생’ 제거와 긴급 화면의 도입 설명 박스 삭제를 캡션에 명시했다.

## 검증

- PNG 파일 2개의 형식과 해상도를 확인하고 이미지를 열어 홈과 긴급 화면의 내용을 대조했다.
- Markdown 이미지 상대경로, 텍스트 예시 교체 위치, 남겨야 할 3~5번 예시를 확인했다.
- `git diff --cached --check`와 `loom validate --strict`를 실행했다.

## 남은 사항과 다음 행동

제공된 이미지 자체의 문구는 편집하지 않았다. 실제 디자인 제작 시 기획서의 최신 표시·삭제 규칙을 이미지에 반영해야 한다. 다른 세 화면의 이미지가 추가되면 해당 예시도 교체할 수 있다.
