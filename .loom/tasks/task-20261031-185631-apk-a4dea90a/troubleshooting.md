# 확인 사항

최종 APK 빌드와 단말QA는 앱 담당자가 진행 중이다. 앱 gitlink는 아직 변경하지 않았으며 메인 API와 기존0.2.1 서브모듈의 일시적 차이는 최종 검증 앱으로 갱신할 예정이다. 관련없는 학습·발표·라이선스 문단은 스테이징하지 않는다.

0.3.0 APK의 실제 지도 경로는 사용자와 앱 담당자 화면 확인을 통과했다. 음성 입력은 준비 직후 취소 보고가 있어 앱 담당자가0.3.1/code5 보완과 재검증을 진행한다. 메인 gitlink를 성급하게 고정하거나 전체 음성QA를 성공으로 기록하지 않고 최종 앱 SHA를 기다린다.

해결: 최종 0.3.1에서 기존 마이크 권한을 먼저 확인하고 최초 권한 요청을 녹음 시작과 분리했다. 사용자가 음성 인식과 상태 반영 정상을 확인했고 native 로그·화면과 서버 revision이 일치했다. 앱 f54cae1로 gitlink 갱신, 원격 재귀 clone과 소스 검사도 통과하여 위 대기 사항은 모두 해소됐다. 다른 채팅의 학습 변경은 그대로 보존했다.
