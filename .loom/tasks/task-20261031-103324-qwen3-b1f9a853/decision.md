# 결정

- 사용자 요청을 같은 A Job의 새 Task로 직접 실행했다. 이전 완료 Task를 재실행하지 않는다.
- 공식 경보 기록은 현재 경보 또는 직접 수신 SMS로 포장하지 않고 historical_replay/simulation, original_sms_available=false, 현재 발효 미확인으로 둔다.
- 과거 영덕 자료로 지역·발표 시각을 좁혀 새 시나리오에서 검색한다. 원래 광범위한 해외 지도 검색 결과는 혼합하지 않는다.
- 원자료가 날짜만 공개하면 해당 날짜 마지막 초를 보수적 상한으로 두고 정밀도를 명시한다. 현재 수집 시각도 별도 보존한다.
- 공식 경보는 모델 출력 외부의 고정 자료로 보존한다. LLM 출력은 요약과 출처에 존재하는 인용만 받으며 수치 피처 필드는 거부한다. 요약은 미검토이고 정책 승인이 아니다.
- 뉴스만으로 NDWS의 수치 격자 피처를 만들지 않는다. 현재 모델 도메인과 수집 자료가 맞지 않아 추론을 blocked로 보존한다.
- 실제 생성은 GPU 서비스의 기존 localhost API만 사용한다. 다른 채팅의 학습과 GPU 서비스 수명주기를 조작하지 않는다.
