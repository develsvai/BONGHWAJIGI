# 문제와 조치

처음 Tailscale Serve 지속 실행은 자동 승인 검토가 명시 승인 부족으로 거절했다. 사용자에게 정확한 Tailnet 전용 HTTPS 노출 범위를 확인한 뒤 사용자가 허용했고 재시도는 성공했다. Funnel은 사용하지 않았다.

HTTPS 서버 자체 TLS 인증서 검증과200 응답은 통과했으나 Mac에서443은 시간 초과다. 읽기 전용 netmap의 실제 PacketFilter가 일반 서버 TCP22만 허용함을 확인했다. ACL을 변경하지 않았고 SSH localhost18080+USB 경로로 단말 검증을 계속한다. 필요한 단말 출발지→일반 서버 TCP443 grant는 별도 승인 범위를 확인해야 한다.

합성 도구의 첫 실행에서 기기 등록을 생략해 위치가404였고, 기타 보호 대상을 남긴 채 독립이동 경고를 기대해 단계 대기 시간이 초과됐다. 기기 등록 후 위치를 저장하고 보호 대상 카드 검증 뒤 독립이동 입력으로 초기화하도록 수정했다. 앱 응답 원문 필드도 original_text로 정합화했다. 이후 등록·3단계·갱신·인증 경계 검증이 모두 통과했다.
