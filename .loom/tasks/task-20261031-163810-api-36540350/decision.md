# 결정

사용자가 직접 요청한 앱 실연동·APK 배포 범위로 서버 API를 배포한다. 기존 DB 볼륨과 자격을 보존하고 GPU·학습은 변경하지 않는다. 사건 종료 근거가 없으므로 신선도를 종료로 취급하는 필드를 만들지 않는다. 합성 mobile-demo 자료와 단말 테스트 좌표를 명시하고 실제 위치를 자동으로 덮어쓰지 않는다.

공식 경보 푸시의 내부ID/공개ID 불일치를 앱 실연동 점검에서 발견했다. 기존 DB 내부ID는 유지하고 발신 직전 API와 공유하는 HMAC 함수를 적용해 본인 인증 조회로 연결한다. 응답 푸시의 incidentID 계약은 유지한다.
