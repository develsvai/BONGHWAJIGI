# 문제와 해결

- origin/hyun02063185가 로컬 remote ref에 없어 ls-tree 조회 실패. 연결된 GitHub 도구로 원격 docs/data-collection 세 문서를 읽었고 브랜치를 병합하지 않았다.
- Kaggle 다운로드 최초 version 1 경로는 404. 공개 메타데이터 currentVersionNumber=2를 확인하고 v2 per-file API의 ZIP 멤버·크기·SHA256·TFRecord CRC를 검증했다. 서명된 리다이렉트 URL이나 인증정보는 기록하지 않았다.
- 일부 국내 포털 페이지를 웹 도구로 읽지 못했으며, 서비스키가 필요한 실제 국내 API/CSV는 확보한 것으로 주장하지 않았다. 기존 인계 표본과 신규 학습 원본을 분리했다.
- 실자료 min/max 감사에서 음수 강수·풍속, 비정상 풍향과 Kelvin 온도가 발견됐다. 검증된 단위와 물리적 제약만으로 NaN 처리하고 원본 범위·처리 건수·모집단 차이를 보고서에 남겼다. 미래 자료로 대체하지 않았다.
- 최초 통합 테스트 fixture는 입력 결측이 정답 불명 픽셀과 겹쳐 제외되어 결측 로더 검사가 실패했다. 정답이 유효한 픽셀에도 입력 결측을 포함하도록 fixture를 수정했고 11개 검사를 통과했다.
- 초기 Ruff 장문/서식 오류는 수정 후 전체 training lint/format 검사를 통과했다.

# 남은 제한

전체 19개 중 3개만 확보, 국내 시간별 확산 정답 미확보, 날짜·좌표 없는 원본의 사건 분리 검증 불가, 사후 집계 입력의 운영 시점 가용성 미확인, 국내 개인 영향 확률 및 보정 미검증. 이 제한은 데이터 문서와 기계 판독 보고서에 포함했다.
