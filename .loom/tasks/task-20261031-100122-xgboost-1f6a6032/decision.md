# 결정

- 사용자 직접 지시로 데이터셋 확보 작업을 foreground 실행했고, 추가 답변 "국외 공개 데이터도 활용"을 근거로 NDWS를 활용했다.
- 프로필·매뉴얼·경보·뉴스를 서비스 입력으로 인정하되 환경 확산 지도학습에는 현재 화재, 기상, 지형/식생/연료 대리 변수와 이후 관측 정답이 필요하다고 구분했다.
- 확보 가능한 정답에 맞춰 첫 데이터 profile을 미국 1km 다음 일별 위성 화재 관측으로 한정했다. 기존 단기 도달/개인 영향/정책 계약을 이 목표로 몰래 대체하지 않았다.
- 최초 실행은 공식 분할 첫 파일 각각 1개로 한정하고 확보 범위와 CC BY 4.0 attribution을 남겼다. 전체 19개 확장을 --all-shards로 지원한다.
- 공식 분할 유지, 분할 간 동일 입력 전부 격리, 내부 동일 입력·정답만 중복 제거. 관측 불가 정답은 제외하고, 이전 마스크 결측과 물리적 불가능 입력은 NaN·플래그로 보존한다.
- 모델은 아직 학습하지 않았으며 작은 실제 DMatrix 검사만 수행했다. GPU serving은 중단하지 않았다. 분석 흐름 구현과 root 의존성을 건드리지 않고 training/ 별도 환경을 사용했다.
