# 결정

사용자의 전체 변경 저장 지시에 따라 기존 미커밋 학습·보고서와 명시된 파일 삭제도 포함한다. 삭제된 예전 라이선스 문서·PPT/ZIP을 되살리지 않는다. 비밀 설정·무시된 원자료는 강제추가하지 않는다.

원격의3커밋은 일반 merge로 보존하고 force push나 rebase로 이력을 재작성하지 않는다. 테스트 실행의 import 경로 문제는 같은 시험을 python -m pytest로 호출하도록 README와 CI만 최소 수정한다.

인증값 검사의 합성 fixture는 정확한 원본 AST 상수 SHA와 테스트/보고서 경로·testcase 문맥으로 확인한 경우에만 구분한다. 실제 인증정보 검사는 계속 적용한다. 진행 중 다른 Task는 완료·취소하지 않는다. Team Policy Snapshot은 없다.
