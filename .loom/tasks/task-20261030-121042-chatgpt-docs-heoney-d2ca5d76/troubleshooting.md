# 문제와 처리

- 웹 조회와 내장 브라우저에서 공유 페이지 열기가 실패했으나, 네트워크 허용 후 공개 페이지 HTML을 확보했다.
- 최초 `loom task run`은 `develop` 필수 브랜치와 현재 `HeoNey` 브랜치가 달라 중단됐다. 사용자가 `HeoNey`로 정책 변경을 승인했고 `loom config policy --required-branch HeoNey` 후 정상적으로 세션을 시작했다.
- 공유 대화 HTML에서 사용자 첨부 이미지의 참조는 확인됐으나 파일 URL의 서명값이 없어 이미지 파일은 복원하지 못했다. 이미지에 대한 사용자 설명·답변 내용과 참조 정보는 문서에 보존했다.
- 원문 외부 인용 중 실제 URL과 연결되지 않은 참조 18개를 `references.md`에 명시했다. 사실을 추정해 다른 링크로 대체하지 않았다.
