# 결정

- 기존 Job의 동일한 문서화 목표 아래 새 Task로 진행했다. 사용자가 승인한 현재 `HeoNey` 브랜치 정책을 Loom 명령으로 적용했다.
- 공유 대화의 사용자 메시지·최종 답변을 원문으로 보존하고, 주제별 정리는 별도 문서로 작성했다. 중복 병합 조각과 내부 도구·시스템 메시지는 공개 대화 원문으로 취급하지 않았다.
- 원문의 시안 태그·코드는 실행하지 않고 텍스트로 보존했다. 답변의 제안과 사용자의 요구 및 이후 변경을 구분했다.
- 기존 설계 문서와 공유 대화 기록의 출처를 분리했다. 더 최근에 제공된 5개 화면 기획서의 내용은 후속 작업에서 반영한다.
